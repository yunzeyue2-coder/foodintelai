📖 产品说

酸辣粉和冒菜，本质是同一个底子——
泡菜泡椒酸辣汤底
。泡菜（酸菜）打底酸，泡椒给发酵辣，姜蒜爆香，辣椒油提色提香。一套底料既能煮红薯粉（酸辣粉），也能烫各种食材按碗卖（冒菜），出摊效率极高。

    工艺只有四步：炒酸辣底料 → 加高汤煮开调味 → 下食材烫熟 → 装碗浇汤撒葱花花生碎。单碗成本¥3，卖¥8-12，毛利率60-75%。

    关键差异：这碗汤底用的是
泡菜酸汤路线
（不是醋勾的酸），酸味有层次、有发酵底韵，回味比普通酸辣粉长。一碗里红薯粉吸饱酸辣汤，再配几片豆皮海带——这就是摆摊的性价比之王。

免费 💀 失败条件

❌ 以下场景 → 直接放弃或重新评估

    

      1. 做酸菜/泡菜味型但用的醋酸调酸 → 吃一口就知道是工业勾兑，没复购

      2. 泡椒没有提前泡好 → 发酵辣味没有渗透进底汤，整锅只有咸味和辣精味

      3. 红薯粉不泡直接煮 → 外软内硬，芯子里夹生

      4. 摊主怕辣 → 汤底需要持续搅动试味，不能一手抖加多泡椒

      5. 选址日均人流量<200人/h → 流量撑不起保本线

      6. 单碗出餐超过3min → 排队超过5人就开始流失

      7. 不想每天换新汤 → 酸菜汤久煮发苦，第二天就不能用了

📋 标准配方

① 炒酸辣底料

    热锅冷油，下姜末蒜末爆香 → 下泡椒碎、泡菜段中小火炒出酸辣味（约2分钟）→ 下一勺辣椒油炒出红油 → 关火备用。

    
② 调汤底

    高汤（骨头汤/鸡汤）入锅烧开 → 下炒好的酸辣底料搅匀 → 调入盐+味精+鸡精+少许白糖提鲜 → 小火熬5分钟让味道融合 → 试味（酸辣咸三味平衡）。

    
③ 烫食材

    红薯粉提前温水泡软（20分钟）→ 顾客点单后：漏勺装红薯粉+豆皮+海带+豆芽+火腿肠 → 入汤煮1-2分钟至粉软透、菜断生 → 捞出。

    
④ 装碗出餐

    碗底铺烫好的食材 → 浇上滚烫的酸辣汤 → 撒葱花+花生碎+少许白芝麻 → 上桌。可配醋/辣椒油让顾客自己调。

🏆 竞品对标

普通酸汤鱼火锅¥8 vs 凯里酸汤鱼小份版¥10-12

    
路边摊做不了酸汤鱼是因为酸汤要发酵，工序复杂，吃一口只有"酸和辣"，没有层次感。泡菜泡椒发酵酸汤是带着豆豉香、椒香、酸菜发酵底韵的复合味——同样卖¥10，用户喝一口汤就知道哪个值。

  

  

    
普通麻辣烫¥15-20 vs 酸辣冒菜¥10-12/碗

    
酸汤鱼火锅动辄¥15-20，小份酸汤鱼一碗搞定¥10-12，性价比肉眼可见。酸汤味型自带开胃属性，比普通火锅更容易"上瘾"。

🚫 避坑指南

• 
红酸汤不先熬香
——红酸汤+糟辣椒一定要下锅熬出酸香味再兑汤，直接丢汤里只会又酸又寡，没有复合底韵。

    • 
木姜子不能用香茅代替
——木姜子香气独特，香茅只有柠檬味没有麻凉感，风味差一个档次。必须用贵州木姜子油（野山椒/二荆条泡椒）。

    • 
鱼片不要煮太久
——鱼片下锅烫30秒变白就要捞，煮久了老柴。提前温水泡20分钟到筷子能夹断即可。

    • 
酸汤鱼不用鲜鱼用冷冻鱼片
——冷冻鱼片没有鲜鱼的胶质和甜味，汤底差一个档次。没用骨头熬的汤，整锅只有酸辣表面的味，没有"厚度"。

    • 
单锅出太多碗
——一锅汤最多出6碗，汤少了味淡了就别续水凑合，换新汤。

    • 
鱼片不浆直接下锅
——不浆的鱼片煮出来又散又老、有辣度分层。成品只有辣没有香，跟醋勾的酸辣粉没区别。
