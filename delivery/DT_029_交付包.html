📋 标准配方

6. 大量杯：量取水和其他液体调料，容量为1 - 2升，刻度清晰准确，材质坚固不易破裂，方便量取不同体积的液体。
8. 保鲜膜：覆盖桶口，防止灰尘、杂质落入，保持糖水的卫生。
3. 冰糖：800 - 1000克，“太古”冰糖是不错的选择。它颗粒均匀，纯度高，甜度适中，能够为糖水增添纯正的甜味，500g装售价约10元。
4. 桂花蜜：200 - 300克，“汪氏”桂花蜜品质较好。蜜质浓稠，桂花香气浓郁，能为糖水增添独特的风味，250g装售价约15元。
8. 加冰块售卖：在出摊售卖前，根据需要将适量的食用冰块加入冷藏好的红豆小汤圆糖水桶中。冰块的加入量可以根据个人喜好和天气情况进行调整，一般建议冰块与糖水红豆小汤圆的比例为1:3 - 1:4左右。加入冰块后，用长柄搅拌勺轻轻搅拌均匀，使冰块迅速降温，营造出冰爽的口感。然后，将红豆小汤圆糖水装入干净的塑料瓶或杯子中，即可开始售卖。

📋 标准配方

1. 处理红豆：将红豆提前用清水浸泡6 - 8小时，使其充分吸水膨胀。浸泡完成后，将红豆捞出，放入大盆中，用流动的清水冲洗2 - 3次，去除表面杂质，沥干水分备用。
2. 煮制红豆：在15升商用不锈钢桶中倒入适量的纯净水，放入沥干水分的红豆，将桶放置在商用电磁炉上，开启大火将水烧开。水烧开后，转中小火，盖上锅盖，慢煮1 - 1.5小时，期间需不时搅拌，防止红豆粘锅。煮至红豆软烂出沙，达到理想口感后，放置一旁备用。
3. 煮制小汤圆：在大锅中倒入足量的清水，大火烧开。水开后，放入小汤圆，并用长柄搅拌勺轻轻搅拌，防止小汤圆粘连。保持大火煮3 - 5分钟，直至小汤圆全部浮起，表明小汤圆已基本熟透。将煮好的小汤圆捞出，放入装有冷水的大盆中过凉，以增强其口感的Q弹度。过凉后，用大漏勺沥干水分备用。
4. 煮制糖水：在煮红豆的桶中，加入剩余的15升纯净水，放入称量好的冰糖，将桶放置在商用电磁炉上，开启大火将水烧开。水烧开后，转中小火，用长柄搅拌勺不断搅拌，使冰糖完全溶解。这个过程大约需要10 - 15分钟，期间要密切关注糖水的状态，防止冰糖粘锅烧焦。待冰糖完全溶解后，继续煮5 - 10分钟，让糖水稍微浓缩，增加甜度和粘稠度。

🚫 避坑指南

2. 小汤圆的煮制：煮小汤圆时水要足够多，且需不断搅拌，防止粘连。煮好后及时过凉，沥干水分，以免小汤圆因水分过多影响糖水口感。
3. 糖的用量：冰糖的用量可根据当地消费者的口味偏好进行适当调整。如果当地口味偏甜，可以适当增加冰糖的用量；如果喜欢清淡一些的口味，可以适当减少。在煮制糖水过程中，可以边煮边品尝，根据实际甜度进行微调。
4. 桂花蜜的使用：桂花蜜的用量可根据个人口味进行调整，喜欢桂花香气浓郁的可以多放一些，反之则少放。添加桂花蜜时，要搅拌均匀，使其充分融入糖水中。
