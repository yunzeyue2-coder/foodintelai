📖 产品说
河南酱肉大包与普通鲜肉包的核心区别是双馅体系：熟酱肉馅出酱香和油润感，鲜肉馅补水分和多汁感。

熟五花肉先煮再切粒，用猪油炒香加甜面酱，酱香稳定、油亮包裹肉粒。鲜肉馅用夹心肉（3肥7瘦）打水，弥补熟肉馅缺的汤汁。一酱一鲜，一油一水，两口咬下去层次全开。

标准60g/个（皮30g+馅30g），适合早餐摊快速出餐。卖¥2-3/个，品牌价最多卖到¥3.5。

🎯 市场对标
酱肉包3-5 vs 普通鲜肉包2-3
普通鲜肉包是生肉馅打水上劲，一口咬开汤汁有但肉香层次单一。酱肉包先用猪油炒甜面酱爆香熟五花肉粒，油脂和酱香先锁进肉里，再跟鲜肉馅混合，一口下去既有酱香油润感又有鲜肉汁水。
💬 话术
河南酱肉大包，五花肉先用甜面酱炒过再包进去的——酱香浓、油润润的。跟普通肉包子不一样，你试一个就知道了。刚出锅的，趁热吃。

📋 工艺流程
【熟酱肉馅（1斤五花肉标准）】
• 五花肉1斤 + 姜葱料酒煮熟，捞出切粒剁碎
• 锅中下猪油100g + 葱蒜少许，小火炒至金黄，捞出葱蒜渣
• 加生姜末20g + 熟五花肉炒香
• 加甜面酱10g + 老抽20g + 鸡汁5g + 味精5g + 鸡精5g + 白糖2g + 白胡椒粉1g + 香油5g
• 炒至酱香均匀附着、略干不出水、油亮包裹肉粒
• 放凉，冷藏或冷冻备用

【鲜肉馅（1斤夹心肉标准）】
• 夹心肉（3肥7瘦）1斤剁末
• 加草菇老抽12g + 料酒6g + 盐5g + 白糖15g + 味精6g + 白胡椒粉2g + 鸡汁3g + 熟猪油10g + 香油5g
• 分次加水100g搅上劲，最后加姜末葱末15g拌匀
• 成型标准：肉馅吃水但不泻水

【面团（1kg粉标准）】
• 面粉1kg + 酵母8-10g + 糖10-15g + 水500-520g
• 揉匀醒发：夏季30-40分钟 / 冬季60分钟
• 揪剂每个30g，擀圆包馅

【包制蒸制】
• 面皮30g + 馅30g = 60g/个
• 包10-14褶，收口捏紧
• 二次醒发8-15分钟
• 水开上锅，大火蒸8-10分钟
• 关火焖2分钟再揭盖（防塌皮）

🚫 避坑
• 酱肉馅必须炒到略干不出水——太湿包进去蒸的时候馅塌了不成型
• 鲜肉馅加水量不能超100g/斤肉——水多了馅泻，包不住
• 两种馅混合比例不要超过1:1——酱肉占主味，鲜肉辅助多汁
• 二次醒发不能省——包好不醒直接蒸，皮发不起来硬皮死面
• 蒸好焖2分钟再开盖——热包子遇冷空气瞬间塌皮
• 酱肉馅可以提前一天预制冷藏，早上直接包效率翻倍
