📖 产品说
韩式辣炒年糕杯跟国内传统炒年糕是两码事。

传统炒年糕是配菜、主食，得坐着吃。韩式年糕杯是杯装街头小吃，竹签插着边走边吃，一份就是一部韩剧的快乐。

灵魂是韩式辣酱底——辣椒醬（고추장）+ 辣椒粉 + 糖稀 + 水芹洋葱出甜，不是中式的豆瓣酱加辣。年糕必须用韩国圆柱年糕（长条切段），口感偏硬有嚼劲、吸水不烂。配上鱼饼片、包菜丝、煮鸡蛋半个，杯底垫年糕、中间铺鱼饼和菜、顶上放鸡蛋，淋两勺热辣酱，撒芝麻海苔碎。

一份成本 ¥2.5-4.0，卖¥10-15。一台小燃气灶+不锈钢锅+保温桶，总投资不到¥1500。

💬 话术
韩剧同款辣炒年糕杯，现点现做！年糕是从韩国圆柱年糕切段，不是普通条糕。配鱼饼片、包菜丝、半个溏心蛋，淋咱们自己调的韩式辣酱，甜辣口不齁不腻。一杯拿着边逛边吃，酱不会洒。来一杯？推荐搭配韩式炸鸡杯一起吃，辣酱和炸鸡酱底是同源配方，味道很搭。
🧠 核心精髓
🌶️ 韩式辣酱底
辣椒酱（고추장）+ 粗辣椒粉 + 糖稀 + 生抽 + 蒜末 + 水芹洋葱水。跟中式的豆瓣/黄豆酱路子完全不同。酱底是韩式小吃的魂，甜辣平衡比辣度重要。
🍚 年糕品种
韩国圆柱年糕（长条型切4-5cm段）。用之前冷水泡30分钟。❌ 不能用火锅年糕片——太薄，煮了就烂。❌ 不用中式条糕——没嚼劲、吸酱太多变糊。
🥟 鱼饼处理
鱼饼片切三角形，每杯放2-3片。提前用热水焯30秒去油腥，沥干后再入酱锅。鱼饼不能久煮，软了没口感。
🧊 杯装结构
底层年糕 → 中层鱼饼片+包菜丝 → 顶层半个煮鸡蛋 → 淋酱 → 撒芝麻海苔碎。鸡蛋用溏心蛋（煮6分半）切开流心最好看，摆摊可用全熟蛋省事。
📋 工艺流程
【备料（出摊前）】
• 年糕冷水浸泡30分钟，沥干
• 鱼饼片切三角形，热水焯30秒
• 包菜切丝，鸡蛋煮熟剥壳切半
• 调酱：辣椒酱+粗辣椒粉+糖稀+生抽+蒜末+水按比例搅匀

【现场出餐（单份流程）】
• 锅中加少许油，下包菜丝炒软
• 加入年糕段，倒入调好的酱和水
• 中火煮3-4分钟至年糕软糯挂酱
• 加入鱼饼片翻匀，煮1分钟
• 装杯：先装年糕垫底 → 铺鱼饼和包菜 → 顶部放鸡蛋 → 淋一勺酱汁 → 撒芝麻海苔碎

【变化】
• 加芝士版：装杯后撒芝士碎，微波或喷枪融化
• 辣度调节：按比例增减粗辣椒粉量
• 酱料可预先调好一锅，保温桶带出摊

🚫 避坑
• 年糕用错品种→口感全毁，必须用韩国圆柱年糕
• 酱底用中式豆瓣酱冒充→顾客吃一口就放回去了，正宗韩式辣酱是辣椒酱+辣椒粉，不是豆瓣酱
• 年糕煮太久→烂糊，煮3-4分钟刚软即可
• 不焯鱼片→鱼饼的油腥味入酱，整锅酱串味
• 糖稀用白糖代替→酱汁挂不住年糕，糖稀的黏稠度和光泽是白糖没法替代的
• 装杯酱汁不够→顾客吃到底下层没味，每杯多淋一勺酱汁差别很大
• 夏天年糕常温放→4小时以上发酸，冰桶+少量多次补货
