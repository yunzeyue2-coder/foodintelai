📖 产品说
韩式辣炒年糕杯不是传统炒年糕——不用坐着吃，杯装边走边吃，竹签插着逛街。灵魂在韩式辣酱底：辣椒醬（고추장）+粗辣椒粉+糖稀+水芹洋葱，这套酱底跟沧林糖醋麻辣酱底（JL_062）同属韩式甜辣体系，摊上如果有韩式炸鸡酱底，直接调糖稀比例就能跨品复用。

年糕必须用韩国圆柱年糕（长条切4-5cm段）——口感偏硬有嚼劲，吸水不烂。配鱼饼片、包菜丝、半个煮鸡蛋，杯底年糕→中层鱼饼包菜→顶部鸡蛋→淋酱→撒芝麻海苔碎。

🏭 产能模型（关键）
🍳 单锅峰值
单锅一次可煮3-4杯量（年糕段450-600g+酱底90-120g+水），每锅出餐3-4分钟，含装杯时间。28cm锅最优容量，换大锅受热不均。
⏱️ 单小时上限（单人）
15锅次 × 3杯 = 45杯/小时（理想）。实际含等待/收钱/补料/清洁，35-40杯/小时。4小时出摊单人最多140-160杯，但峰值仅前2小时，后2小时掉量。所以日销100杯已是单人天花板。
👥 双人模型
1人专职煮+1人装杯收钱补料，产能提升至50-55杯/小时。6小时旺季冲150杯。双人优势：午晚连摊+打包外带，峰值不再卡在人效。
🚫 产能瓶颈
① 锅不够（建议备2个锅轮换）② 装杯区太小（操作台至少60cm宽）③ 酱底不够预装挤酱瓶④ 顾客排队超过5人开始流失——产能跟排队长度直接相关。
🌀 味觉曲线（复购的核心）
第一口甜辣冲鼻（糖稀+고추장的前置甜味，粗辣椒粉的微呛感）→ 瞬间打开食欲
中段年糕的嚼劲释放淀粉甜 → 酱的乳酸发酵味（고추장的深度）→ 鱼饼的鲜味中和辣感 → 包菜的清脆解腻
最后一口酱底收尾的咸+回甘（糖稀残留的余甜+生抽的底咸）→ 留在舌侧的不是辣是甜，产生"再来一口"的冲动
⚡ 酱的成瘾结构：甜（入口触发）→ 辣（中段推进）→ 回甘（收口锚定）→ 咸鲜（平衡不腻）。四次递进，缺一不可。
复购关键不在辣，在"收口的回甘"——糖稀的残留甜度让顾客吃完还想吃。
🧪 酱料工程标准化
📐 粘稠度（挂杯率）
标准：25-30秒挂杯时间（勺背沾酱垂直流下，以勺背完全流净不挂厚膜为准）。
太稀→年糕不挂酱，味道浮在表面。太稠→黏嘴腻口。
调节：加糖稀增稠，加水稀释，每次±20g调整。
🍬 Brix甜度区间
标准Brix值：32-38°Bx（手持糖度计测量）。
低于30°→偏咸不甜，韩式感弱。高于40°→齁甜，第二口就腻。
调节：糖稀每±20g变动约2°Bx。韩式辣椒酱本身含糖（约25-30°Bx），占总甜度50%。
🌡️ 热稳定性
测试：酱底煮好后保温70°C 2小时，观察是否分层/油水分离。合格标准：保温后搅拌10秒恢复均匀，无水分析出。
问题：加水过多→油水分离。糖稀不足→分层加快。生抽过多→加热后变苦。
解决方案：酱底熬好后加5g玉米淀粉+10g水勾芡，增加乳化稳定性。
🌶️ 辣度梯度
微辣（初阶）粗辣椒粉60g+番茄酱30g → 中辣（标准）粗辣椒粉100g → 重辣（进阶）粗辣椒粉150g+辣椒精2-3g
核心：辣度靠粗辣椒粉的颗粒感传递（不是辣椒精的刺辣），颗粒感在舌面缓慢释放，是"有层次地辣"不是"一口辣翻"。
🧂 盐度锁定
标准盐度：1.0-1.2%（即1000g酱底含盐10-12g当量）。
实测：500g酱底配比中，韩式辣椒酱含盐约4g+生抽60g含盐约6g=总盐10g → 盐度1.0%。
不够咸加5g鱼露（比加盐更有层次感），过了加糖稀中和。

📋 全流程SOP
【出摊前夜·备料40分钟】
• 年糕5kg切4cm段，冷水浸泡密封冷藏过夜
• 酱底按批量配方熬好冷却，密封冷藏
• 鸡蛋55个煮全熟，剥壳切半装盒冷藏
• 鱼饼2kg切三角形，焯水30秒沥干装盒冷藏
• 包菜2颗切细丝装袋冷藏
• 芝麻海苔碎分装小袋

【出摊前·装车15分钟】

• 食材装保温箱（夏天加冰袋）
• 纸杯100个+竹签100根+手套+围裙+口罩
• 酱底装挤酱瓶
• 电子秤+计时器+抹布
• 招牌+价格牌+收款码+灯带
• 折叠桌+椅子

【开摊·前30分钟】
• 摆折叠桌、支招牌、挂灯带
• 锅中加水烧开
• 年糕从冷水捞出沥干装盆（冰桶上放）
• 酱底挤酱瓶+包菜丝+鸡蛋半+鱼饼片+海苔碎各装小盒
• 试做1杯：测咸辣度，必要时微调

【高峰期·流水线·一次炒3杯】
① 炒底（30秒）
大火烧热锅 → 油10ml → 下包菜丝150g（3杯量）翻炒15秒 → 下年糕段450g → 加酱底90g → 加开水50ml → 中火

② 煮年糕（3-4分钟）
中火煮的同时刮刀不断翻动（防粘锅+让每段年糕均匀挂酱）→ 年糕变软透明状 → 下鱼饼片6片翻匀煮30秒 → 关火

③ 装杯（30秒）
夹子先装年糕垫底（填满杯底1/3）→ 铺鱼饼片2片+炒软的包菜丝 → 杯顶放半个煮鸡蛋（切面朝外）→ 淋一勺酱汁 → 撒芝麻海苔碎

【收摊10分钟】
• 剩余食材回收（年糕不可隔夜直接报废）
• 酱底密封冷藏可再用2-3天
• 锅具清洗擦干

💀 失败条件（什么情况不能干）
❌ 以下场景→直接放弃或重新评估
1. 摊位周边50m内已有2家以上韩式炸鸡/年糕摊 → 同质化竞争，拉低售价至¥8-10无意义
2. 选址日均人流量<300人/小时（非学生区/非夜市核心区） → 流量撑不起60杯/天的保本线
3. 夏季无冰桶冷链条件 → 年糕2小时发酸报废，损耗率飙至20%+
4. 单人出摊但选址属于"必须排队才有生意"的夜市 → 人效瓶颈（35杯/小时）撑不起排队长龙
5. 摊主不能连续4小时站锅操作（备料+煮锅+装杯全程站着） → 体力门槛比想象高
6. 目标日营收¥800以下 → 固定成本（摊位费+设备折旧）占比超30%，薄利没意义
7. 酱底做出来Brix<30°或盐度>1.5%且不会调 → 酱底不合格就没有复购
🚫 避坑
• 年糕品种搞错→全部白费，必须韩国圆柱年糕
• 年糕不泡冷水→外烂里硬，泡30分钟不可省

• 鱼饼不焯水→油腥入酱整锅串味
• 糖稀用白糖代替→酱挂不住年糕
• 酱底不做热稳定性测试→保温2小时分层
• 不试味就出摊→每批酱调完先做一杯
• 酱底没有挤酱瓶→用勺浇不均匀，装杯太慢
• 一个人忙不过来还接大单→高峰期控制，宁可等不能糊弄
• 成本账只算直接成本→忽略损耗和摊位费分摊
• 夏季年糕不加冰桶→4小时发酸报废，损失直接吃掉利润
