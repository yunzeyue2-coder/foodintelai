📖 产品说
紫薯燕麦粥——早上掀开锅盖，整锅紫红色的浓粥冒着热气，紫薯的天然花青素把粥染成天然的莫兰迪紫，燕麦片在粥里吸饱了水变半透明，挂上粥浆微微拉丝。

吴师傅把糯米+大米搭起来：糯米提供黏度和绵密口感，大米保持清爽不糊嘴——纯糯米粥一碗下去胃酸，纯大米粥太稀挂不住胃。

紫薯进去煮到化开，花青素在粥里散开形成天然紫色，不需要任何色素。最后才放燕麦片——闷泡10分钟而不是煮，燕麦保留咀嚼感不会被煮成糊。

成本¥2/碗，卖¥6-8，毛利率70%+。出餐就是盛碗，几乎没有花样——但正因为简单，核心在粥底和食材搭配。粥底浓稠度是灵魂：太清像汤，太稠像饭。

适合早摊、糖水铺、养生餐线——能做早餐也能做下午甜品。

🏭 产能模型
🍳 熬粥流程
1锅出10碗（约3L粥）。前一晚泡米2h → 出摊前20-30分钟开始熬 → 大火烧开转小火40分钟 → 加紫薯粒煮至化开 → 加燕麦片闷泡10分钟 → 加冰糖搅化 → 保温。
⏱️ 出餐速度
盛碗即出——顾客点单直接舀，5秒/碗。没有二次加工，高峰期可以用大锅提前多熬一锅轮流保温。
👥 单人操作上限
熬粥是提前备好的，出摊就是保温+盛碗。单人可同时照看2锅（共20碗存量）。熬粥间隙可做其他准备工作。
早摊建议熬2锅，预留40-60碗的量。
♨️ 保温技巧
熬好装入保温桶（10L）出摊。粥在保温桶里持续保温4-6小时不变稠（比起明火保温，保温桶不易糊底）。出摊前可以提早全部熬好装桶，到摊位直接开卖。现场吃用碗，外带用纸碗+盖。
🌀 味觉曲线
第一口紫薯的天然甜味先到——不是砂糖的死甜，是紫薯自带的绵密甘甜。粥体浓稠顺滑，米粒已经煮到半融化，挂勺不滴。
中段燕麦片带来咀嚼感——不是泡烂的糊状燕麦，是保留了一点嚼劲的整粒燕麦片，跟细滑的粥底形成软+弹的双重口感。冰糖的甜均匀分布在每一口里，不抢紫薯味。
最后一口碗底剩下深紫色的精华——紫薯花青素沉底+燕麦胶质+米汤混合，最浓稠的一口。喝完了嘴里是干净的米香和紫薯的回甘，不会腻人。留下"还想再喝一碗"的冲动。
⚡ 紫薯燕麦粥的复购依赖两点：① 紫薯选得好（甜度高、花青素多，颜色紫得深）② 粥底浓稠度稳定（不稀不稠）。
顾客一旦喝到"正好对味"的浓稠度，就会记住你这个摊的粥底。
🧪 配方标准
📐 核心配比（1锅≈10碗）
  • 糯米 150g + 大米 350g = 500g米
  • 紫薯 250g（去皮后净重）
  • 燕麦片 150g（整粒型，非即溶粉）
  • 冰糖 60-80g（依紫薯甜度微调）
  • 水 约2.5-3L（粥:水≈1:6）
🥣 关键工艺参数
  • 米泡水≥2h（吸足水再煮，米粒易烂粥更绵）
  • 紫薯去皮切1cm小粒（太大不易煮化，太小失去存在感）
  • 熬粥40分钟后再加紫薯（紫薯不耐久煮，提前加会煮到颜色发暗）
  • 加紫薯后再煮15-20分钟至紫薯软烂能用勺压开
  • 关火→加燕麦片→盖盖闷泡10分钟（不煮，煮了燕麦成糊）
  • 最后加冰糖搅化（冰糖后放不抢紫薯甜）
✅ 品控标准
  • 粥体：挂勺不滴、不泄水（放了15分钟不出水层）
  • 颜色：均匀紫红色（天然花青素，非色素）
  • 紫薯粒：软烂一压即开，但不是完全没形状
  • 燕麦：整粒可见，咀嚼有弹牙感
  • 甜度：微甜不齁，紫薯天然甜为主，冰糖只是辅助

紫薯燕麦粥有以下天然场景优势：
① 早晚两用：早上当热粥暖胃，下午加冰/放凉当糖水
② 颜色吸睛：紫红色的粥拍照发小红书天然出片——天然花青素紫不是色素调出来的
③ 健康标签强：紫薯含花青素+燕麦含β-葡聚糖——"喝粥等于抗氧化"是很好的卖点
④ 季节性弱：冬天热粥暖胃、夏天放凉/加冰块成紫薯燕麦冰粥——全年都能卖
📋 全流程SOP
【出摊前夜·备料30分钟】
• 糯米+大米淘洗2遍，清水浸泡≥2小时（可过夜）
• 紫薯洗净不去皮冷藏（紫薯遇空气易干，带皮冷藏保存）
• 检查燕麦片存货、冰糖量

【出摊前·熬粥40分钟】
• 泡好的米沥水 → 冷水下锅（米:水≈1:6），大火烧开撇沫 → 转小火盖盖40分钟，中途搅拌2-3次防粘底
• 紫薯去皮切1cm小粒
• 熬粥30-35分钟后（粥已基本浓稠）→ 加紫薯粒 → 搅匀继续煮15-20分钟至紫薯软烂、用勺能压开
• 关火 → 倒入燕麦片 → 搅匀 → 盖盖闷泡10分钟（严格不要偷吃，不煮）
• 加冰糖搅化 → 装入预热过的保温桶 → 出摊

【出餐·5秒/碗】
• 保温桶打开 → 舀粥 → 装碗（当场喝用瓷碗，外带用纸碗+盖）
• 外带配勺子+餐巾纸
• 建议在保温桶上加个小牌子"紫薯燕麦粥 ¥6-8"

【收摊10分钟】
• 保温桶剩粥倒入带盖容器冷藏（第二天可加热再卖，但口感略差，建议当天卖完）
• 锅具泡水清洗（紫薯+米含有大量淀粉，干了很难洗）
• 未用完紫薯用湿毛巾包好冷藏（最多放3天）

紫薯燕麦粥，¥6一碗！这个紫色不是色素，是紫薯自己煮出来的花青素，天然的。我先把糯米大米熬了40分钟到浓稠，再加紫薯熬化，最后加燕麦片闷泡——燕麦不是煮烂的，能吃出整粒的口感。甜用的冰糖，不是白砂糖，不会齁。早上一碗暖胃热量也不高。来一碗？可以加个卤蛋组合只要¥9。
🎯 市场对标
紫薯燕麦粥 vs 普通八宝粥/小米粥
普通早摊的粥大多是白粥¥2-3、小米粥¥3-4、八宝粥¥5——竞争激烈，利润薄。紫薯燕麦粥用颜色差异化（天然紫色）和口感分层（绵密粥底+整粒燕麦咀嚼感）打出溢价空间。

定价¥6-8匹配糖水铺的价位带（糖水¥8-15），但对标的是早摊粥（¥2-5）。优点是：摊位边路过的人看到一锅紫色粥自然会好奇"这是什么粥"，有天然话题性。加上"花青素""抗氧化"的健康话术在女性客群中转化率高。

风险：紫薯粥出品稳定性不如白粥——紫薯本身甜度不稳定（同一批紫薯甜度差异很大），冰糖量需要每天微调。另外紫薯成本波动大，淡旺季价差可达一倍。
对标失败案例
很多紫薯粥翻车在：紫薯用太少颜色太淡没卖相 → 顾客以为是白粥加了紫色料；紫薯买老了纤维太粗没煮化 → 粥里面有硬丝；燕麦片跟紫薯一起放进去煮 → 燕麦煮到化开粥变成一锅糊紫色糊糊，毫无口感层次。
💀 失败条件
❌ 以下场景→直接放弃或重新评估
1. 紫薯价格高于¥8/kg的月份（冬季）→ 成本控制不住，毛利率跌破50%
2. 只卖紫薯粥一个单品，没有其他搭配（卤蛋/包子/油条/咸菜）→ 复购靠啥？顾客吃腻了粥下次不来
3. 煮粥水品控不稳定（粥太稀或太稠）→ 粥类摊位最致命的问题就是浓稠度天天不一样
4. 使用普通红薯冒充紫薯（省成本）→ 颜色出来的灰色+紫色混合很恶心，卖相直接劝退
5. 紫薯不新鲜（切开已经发黑/空心）→ 煮出来粥底发暗灰色，花青素被氧化了
6. 目标日营收¥200以下 → 熬一锅粥的投入（时间+燃气+备料）跟收入完全不成正比
7. 地段老年客群为主但定价¥8 → 叔叔阿姨心里价位¥3-5，¥8的粥他们会觉得不值
🚫 避坑
• 紫薯别买太大→大紫薯纤维粗，煮出来没小紫薯绵
• 紫薯切太早→氧化变黑，切好后马上泡水防变色
• 加紫薯太早→煮久了花青素变质，颜色从紫红变暗灰
• 燕麦片煮不是闷→燕麦煮了变糊糊，毁掉口感层次
• 大米占比太低→粥底太黏像糯米饭，口感不对
• 糖用白糖→白糖甜得尖锐，跟紫薯的天然甜不搭
• 熬粥不搅拌→米和紫薯淀粉容易糊底，味道发苦
• 保温桶不预热→冷桶倒热粥瞬间降10°C，到顾客手里温吞吞
• 紫薯不新鲜→紫薯一见光就氧化，放超过5天的紫薯煮出来颜色发灰
