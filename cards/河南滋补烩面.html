📖 产品说
河南滋补烩面的本质是汤、面、料三位一体——不是单吃面也不是单喝汤。

羊骨羊油熬4-6小时出乳白浓汤，高筋面粉加盐加油反复醒扯出的宽面韧而不硬，熟羊肉片、豆腐皮、粉丝、黄花、木耳、鹌鹑蛋、当归枸杞七料齐聚。

胡椒是灵魂——一勺白胡椒粉下去，暖感从胃里穿透全身。中药味不能重，当归枸杞只是"滋补标签"，不是主味。

单碗成本¥3.5-5（含面含肉），售价¥10-18/碗，是能开店的硬核品类。

📋 工艺流程
【羊汤熬制（100斤水标准）】
• 羊肉3000g + 羊骨架6000g + 羊油750g
• 大葱250g + 生姜100g
• 羊骨架冷水浸泡去血，羊肉焯水冲洗
• 100斤水下锅，大火烧开撇沫
• 转中小火熬4-6小时，保持微翻滚
• 汤色乳白略清、羊香+油香、不腥不腻不浑
• 羊肉煮至筷子能扎透（约1.5-2小时）捞出晾凉切片

【香料包】
花椒10g · 八角15g · 山奈5g · 桂皮5g · 草果5g · 丁香2g · 良姜5g · 小茴香5g

【烩面坯（10kg高筋粉标准）】
• 高筋面粉10kg + 盐200g + 水约5-5.5L + 色拉油250g
• 揉匀醒面30分钟 → 搓条揪剂 → 刷油醒2小时以上
• 关键：醒面+拉伸+筋性控制，不断、可拉长、入口有韧性

【出碗标准】
• 碗底：熟羊肉片 + 豆腐皮丝 + 粉丝 + 黄花 + 木耳 + 去皮鹌鹑蛋2个
• 滚烫羊肉汤做面汤，拉好的宽面直接在羊汤里煮2分钟捞入碗
• 面条的淀粉融进汤里，汤底更浓更挂味——这是原汤煮面的精髓
• 点缀：枸杞6-8粒 + 当归1片 + 香菜段 + 香油
• 每碗调底味：盐6-8g + 白胡椒粉1-2g（灵魂） + 鸡精1g + 味精1g

🚫 避坑
• 面坯必须醒够2小时以上——没醒透拉不长一拉就断
• 羊汤熬过头会发酸——控制在6小时以内
• 当归不能多（10-15g足够）——多了药味抢羊汤风头
• 鹌鹑蛋煮好去皮冷藏备用，出碗前放汤里烫一下即可
• 豆腐皮/粉丝/木耳/黄花泡发时间不同——统一泡发时间：粉丝温水30分钟、木耳2小时、黄花1小时、豆腐皮切丝即用
• 羊油750g看着多，实际煮汤时很多会浮去——不要减，少了汤不香
• 香辛料用纱布包好——喝汤喝到花椒粒很扫兴
• 夏天羊汤淡季——可搭配凉皮、凉拌羊肉、凉拌豆腐皮互补
