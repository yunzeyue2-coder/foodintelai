📖 产品说
水果绵绵冰是夏季摆摊的经典甜品——冰底用牛奶打底，绵密细腻；自熬水果酱酸甜浓郁，搭配新鲜水果丁、脆波波、椰果，一碗料足颜值高。

冰底配方——纯牛奶500g + 炼乳80g + 白糖50g + 淡奶油100g，搅匀后冷冻成冰块。

水果酱熬制——草莓/芒果/西瓜（任选一种，推荐芒果&草莓）500g + 白糖100g + 柠檬汁10g，小火熬至浓稠，冷却待用。

出餐流程——冰底用刨冰机打成绵冰铺碗底 → 浇上水果酱 → 装饰新鲜水果丁 + 脆波波 + 椰果 + 炼乳。一碗出餐只需2-3分钟。

📋 工艺流程
【冰底预制（10份量）】
• 纯牛奶500g + 炼乳80g + 白糖50g + 淡奶油100g，充分搅匀至糖完全融化
• 倒入冰格/冻冰盒，冷冻≥8小时（过夜最佳）
• 冻好的冰底可提前一晚做好，出摊前直接装保温箱搬运

【水果酱熬制（约8-10份量）】
• 新鲜草莓/芒果/西瓜 500g，洗净去皮去核，切小丁
• 加白糖100g、柠檬汁10g，搅拌均匀静置15分钟出汁
• 小火慢熬15-20分钟，期间不断搅拌防糊底
• 熬至浓稠、果肉软烂即可关火，冷却后装瓶冷藏
• 草莓酱建议当天熬当天用，芒果酱可冷藏3天

【出餐流程】
• 冻好的冰底从冰箱取出，用刨冰机打成绵密冰沙
• 碗底铺满绵绵冰（约200-250g），中间稍微堆高
• 浇上水果酱2-3勺（约40-50g），让酱汁顺冰面自然流下
• 装饰新鲜水果丁、脆波波、椰果各一小把
• 最后淋一圈炼乳（约10g），插勺上桌
• 出餐时间：2-3分钟/份

【高峰期节奏】
• 冰底提前一晚冻好，出摊带两箱（约30-50份量）
• 水果酱出摊前熬好装瓶，到摊位上直接浇
• 一人在刨冰机前刨冰装碗，一人加料浇酱收钱
• 高峰期1小时出30-40份

🚫 避坑
• 冰底牛奶比例不能太少——牛奶少了冻出来是冰碴不是绵绵冰，必须加淡奶油增加绵密感
• 水果酱不能熬太干——冷后会变硬，浇到冰上推不开。熬到浓稠但仍有流动性就关火
• 草莓酱氧化变色快——出摊前熬好放在瓶子里冷藏，不要提前暴露在空气中
• 刨冰机不同型号出冰粗细不同——买之前试机，确认能打出绵冰不是碎冰
• 出摊前确认电源——刨冰机功率约300-500W，普通电动车电瓶+逆变器够用
• 炎夏化得快——冰底打好后立即加酱加料，拍照不超过30秒赶紧出餐
• 水果丁现切现用——切好放久了会氧化变黑，影响卖相
• 气温超过38℃时建议备一箱干冰/冰块把冻冰底盖好防提前融化
