🏭 产能模型
单锅峰值
一次炒1份（锅径30cm为佳），每锅炒制2分钟+备料1分钟。超过1份面条翻拌不均匀，火力不够。
单人1h上限
理论12份/h ↔ 实际7-8份/h（含收钱、补料、等水煮沸）。高峰时段提前备好煮好的面条可提升到10份/h。
双人模型
1人专职炒+1人煮面/打包/收钱。产能提升至14份/h，日产能轻松突破100份。
产能瓶颈
①煮面锅太小 ②没提前备好凉水面条 ③单锅只能炒一份 ④排队超3人顾客走人
🌀 味觉曲线
第一口 孜然焦香直冲鼻腔——大火炒出的孜然颗粒在锅中焦化，混合猪肉的油脂香，打开食欲阀门
中段 面条的筋道嚼劲释放淀粉甜 → 猪肉丝的肉汁鲜味 → 洋葱青椒的脆爽解腻 → 胡萝卜丝的自然甜感缓冲
最后一口 酱油的咸香+孜然的余味在口腔回旋，底味不辣不麻，是「很香想再来一口」的收尾
复购关键在孜然的「层次感」——不是撒一把孜然粉了事，而是让孜然在高温下释放三种香：干香（入锅焦化）、油香（油脂融合）、后香（咽下去后舌根回香）。普通摊只做了一层，你做三层就是一个记忆点。

📋 全流程SOP
出摊前夜（备料30分钟）
• 猪肉切丝，料酒+老抽+淀粉抓匀，冷藏备用（可提前切好60份量冷藏）
• 洋葱/青椒/胡萝卜切丝，分装保鲜袋冷藏
• 面条整袋冷藏（鲜面不可冷冻，否则发粘）
出摊前（装车10分钟）
锅×2（1个煮面锅+1个炒锅）+ 炉头×2 + 漏勺/锅铲/长筷 + 油瓶+酱油瓶 + 碗碟+打包盒 + 食材盒 + 冰袋保鲜
开摊前30分钟
① 摆摊+灶具就位 ② 试火试油 ③ 煮一锅面（先试一批，确认面条筋道度） ④ 食材盒依次摆好 ⑤ 孜然粉提前称好用小碗装着
高峰期流水线
① 煮面（3min）：大锅水烧开，下面条煮至8成熟（中心带白芯），捞出过凉水沥干，拌少许油防粘。
② 滑肉丝（30s）：锅烧热下油，大火滑炒肉丝至变色出香，盛出备用。
③ 爆香（45s）：同一锅加油，下洋葱丝+青椒丝+胡萝卜丝大火爆炒，边缘微焦出香。
④ 合炒（90s）：加入沥干的煮面条，大火快速翻炒，让面条充分吸收锅中香气。
⑤ 调味（20s）：撒孜然粉+淋酱油+盐+味精，快速颠锅翻匀，让每根面条裹上香料。
⑥ 装盒（20s）：倒入打包盒，撒熟白芝麻，盖盖。
⏱ 总计约8分钟/份
收摊（10分钟）
剩余生面条冷藏明天可用；炒好的肉丝冷藏；锅具清洗+灶具关火收好；对账+￥收好

💀 失败条件
❌ 以下场景 → 直接放弃或重新评估
1. 周边夜市已有1家及以上主打孜然炒面的摊 → 同质化拉低售价
2. 选址日均人流量＜200人/h → 流量撑不起保本线
3. 不能同时配备煮面和炒面的双炉头 → 产能卡死，出餐5份/h后崩盘
4. 面条先大量煮好放凉，客人点后直接炒 → 面条发坨，口感差
5. 摊主不愿意现场大火爆炒（怕油溅/怕脏）→ 出不了锅气，没有烟火气
6. 目标日营收＜¥400 → 固定成本占比超过30%
7. 孜然粉买便宜货（掺淀粉的调和粉）→ 没有香气记忆点，不如不做
📐 量化失效阈值：日销＜25份→模型失效 · 单份出餐＞10min→崩盘 · 毛利率＜50%→不成立 · 损耗率＞8%→盈亏线以下
🚫 避坑指南
• 面条不过凉水直接炒 → 发粘成团，怎么翻都翻不开
• 过凉水后不沥干 → 下锅后变成煮面不是炒面
• 孜然粉一开始就下锅 → 炒太久发苦。要最后下，利用余热激发香味
• 肉丝腌太久（＞2h）→ 出水变柴。腌5-10分钟够
• 油放太少 → 面条粘锅，锅气不足。炒面油要比想象的多30%
• 只做一个口味 → 至少分出微辣·孜然重·酱油重三档，回头客多点选择
• 忽略成本中的纸巾和竹签 → 虽然少但顾客每天拿，一个月也有¥30-50
