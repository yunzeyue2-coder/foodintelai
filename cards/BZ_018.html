发现这款产品
成都一个菜市场边上，有个大姐摆摊只卖包子——她不做肉包，只做素包，而且只有一个口味：麻辣素包。我一开始不信，纯素包能好吃到哪里去？买了一个，第一口就被打脸了。

馅料是大头菜（就是芥菜疙瘩）切丁，配泡软的龙口粉丝，炒得嫩嫩的鸡蛋碎，加上老干妈一拌——那个红油渗进粉丝里，大头菜嚼起来脆脆的，粉丝滑、鸡蛋香、麻辣味足。吃出了肉包的口感，但是一点都不腻。

更关键的是：成本低得吓人。一笼8个包子，成本才2块8。素包子卖得比肉包便宜，但利润比肉包还高。大姐出摊，早上6点到10点，一天能卖20多笼，周末翻倍。

她跟我说了一句话我印象很深："肉包你得跟菜市场猪肉价赛跑，素包不用，老干妈一瓶3年没涨价。"

制作工艺
  1. 大头菜处理：大头菜去根称重 → 切丁 → 用1-2克盐杀水10分钟 → 挤干水分
  2. 拌油锁水：挤干的大头菜丁与料油（80克）拌匀，让油锁住水分
  3. 粉丝处理：龙口粉丝温水泡软 → 沥干 → 切短段（约3cm）
  4. 鸡蛋炒嫩：2个鸡蛋打散 → 热锅少油小火炒嫩 → 捣碎备用
  5. 混合调味：大头菜丁 + 粉丝段 + 鸡蛋碎 + 所有调味料 → 充分搅拌均匀
  6. 包制蒸制：常规包子皮包馅 → 醒发15分钟 → 开水上锅蒸8-10分钟
配方关键点
大头菜必须去根称重——根部的老筋纤维粗硬，切丁后口感差，一定要先去根再称重保证配方比例准确
杀水不能省——大头菜含水量高，不杀水包进去一蒸全塌了。1-2克盐抓匀腌10分钟，挤干后和料油拌匀，油封住水分馅才滋润
老干妈任意口味都行——风味豆豉、油辣椒、香辣牛肉味……各品牌、各口味效果都不错，麻辣打底就行。50-80克根据当地能吃辣的程度微调
粉丝别泡太软——温水泡10-15分钟就行，泡到芯还带一点点硬正好，切段后拌进馅里还会继续吸水
腐乳是秘密武器——10克腐乳捣碎拌进去，提鲜增香，让素馅有厚度，吃起来不像"吃草"

避坑指南
大头菜杀水必须到位——切丁后撒盐抓匀，等10分钟出水，然后用力挤干。不挤干的后果：蒸出来一兜水，面皮湿透塌成面糊，馅料味道也被稀释了
料油别省钱——料油是麻辣素包的灵魂之一。家里熬的料油（葱姜八角炸香过滤）比色拉油香得多。如果嫌麻烦，至少用熟油
老干妈量要试——50-80克这个范围不是随便写的，当地人口味偏淡就50克，偏重就80克。第一次做建议从50克开始，客人反馈"不够辣"再往上加
粉丝别切太长——切到2-3cm左右，太长了包的时候戳破皮，吃起来也狼狈，一咬粉丝拖老长
鸡蛋要嫩不要老——小火慢炒，刚凝固就关火，捣碎。鸡蛋炒老了硬邦邦的，和其他馅料口感不搭
