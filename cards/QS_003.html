🔪 工艺路径
① 鸡肉腌制
冻鸡翅/鸡腿清水解冻 → 浸泡1-2小时去血水（每40分钟换水一次）→ 划花刀 → 加奥尔良腌料5g+鸡精粉5g+白胡椒粉0.5g+姜葱汁15g+水25g → 腌制1小时以上。
② 调裹浆
炸鸡粉200g + 生粉30g + 鸡蛋1个 + 清水310g → 搅匀成稀糊 → 静置5分钟（让粉类充分吸水）。
③ 裹浆裹糠
腌好的鸡肉 → 筷子夹出滴干 → 裹一层薄浆 → 沾满黄金面包糠 → 抖掉多余的。
④ 油炸
油温170-180°C → 下鸡块 → 炸5分钟至金黄酥脆 → 捞出控油（必须控干油再裹酱，否则酱挂不住）。
⑤ 裹酱成品
炸好的鸡块趁热 → 刷上/拌匀选定的酱料 → 撒熟芝麻和花生碎。可选：甜辣/蜂蜜芥末/酱油蒜香/糖醋蜜汁/果酱。
