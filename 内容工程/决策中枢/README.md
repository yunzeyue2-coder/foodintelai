# 决策中枢 · Decision Priority Engine

## 唯一主链路

```
信号 → 决策卡 → 内容输出 → 工具验证 → 用户行为 → 信号增强
```

所有模块服务这条链。不偏移。

## 信号生命周期

系统不积累垃圾。信号有寿命。

```
新信号  →  观察期（3天）
  ↓
验证期（7天）
  ↓
成立 → 强信号（入库）
  ↓
衰减 → 退出Top信号
  ↓
死信号（清理）
```

超过30天未验证的信号自动进入死信号池。

## 内容三级

不写没有层级的内容。

| 级别 | 性质 | 字数 | 频次 | 生命周期 |
|------|------|------|------|---------|
| L1 | 原子判断（快） | 300-800 | 日更 | 1-3天 |
| L2 | 案例文章（核心） | 1200-2500 | 周3-4篇 | 1-2周 |
| L3 | 方法论（沉淀） | 2000-4000 | 月2-3篇 | 长期资产 |

## 每日决策

> 不允许结构好看却不知道今天押什么。

**每天操作前先答三问：**
1. 今天哪个信号最强？（信号分最高）
2. 这个信号对应什么决策？
3. 这个决策产出什么内容？（L1/L2/L3）

答不出来不写。
