# 内容工程系统 v1.0

## 一、定位

**我们是：** 食品创业决策系统——给产品技术、市场分析、经营方案
**客户：** 小本创业者 / 门店老板 / 工厂研发
**变现：** 知识 → 服务 → 咨询（逐级升单）
**核心逻辑：** 内容建信任 → 习惯依赖 → 私域引流 → 长期复利

## 二、平台任务分解

### 📢 公众号（根据地）

**字数：** 1200-2000字
**结构：**
- 开头：一个画面/一段对话/一个细节（阿城式起笔，不用引语）
- 正文：故事裹着数据走，不要单独列表
- 结尾：不写"总结"，写一个画面收尾 + 一句"我在微信等你"
- 配图：3-5张（1头图 + 2-3张工艺/食材/工作场景 + 1张"字迹"类收尾图）
- 发布时间：**11:00-12:00** 或 **17:00-18:00**
- 引流：文章末尾不写"加微信"，写"搜一个不存在的词"——例如"想知道后面发生了什么？搜'卤锅前传'"，公众号自动回复里给微信

### ❓ 知乎（信任建设）

**字数：** 回答800-1200字 / 专栏2000-3500字
**结构（回答）：**
- 第一句直接给硬结论（"这事能赚，但有三个坑你没看到"）
- 中间拆过程：每个坑一段，配数据
- 结尾：留个钩子"我在公众号连载了这个系列，搜xxx"
**结构（专栏）：** 公众号文章的扩展版，加完整数据/图表/分析
**发布时间：** **10:00-11:00** 或 **20:00-22:00**
**引流：**
- 个人简介写"公众号：沧林观局"（知乎允许）
- 文章末尾"我在公众号'沧林观局'写了完整版，配了3张数据图"
- 不直接放微信/二维码

### 📕 小红书（认知渗透）

**字数：** 300-600字
**结构：**
- 标题：反常识/具体数字/冷幽默（"为了搞明白鸭腿毛利率，我蹲了一周菜市场"）
- 封面图：一张高质感食物特写（暖调/暗调/手工感——禁止ins风）
- 正文：口语化短句，有画面，冷幽默夹着干货
- 配图：6-9张（1封面 + 1-2食物细节 + 1配方截图 + 1工作场景 + 1文字截图）
- 标签：5-8个精准标签
- 发布时间：**12:00-13:00** 或 **18:00-20:00** 或 **21:00-22:00**
- 引流：正文不放任何联系方式。评论区"想要xxx的扣1我私你"→私信→引导微信
- 免费流量：参与小红书「热门话题」「流量扶持计划」，每周至少参与2个话题

### 💬 微博（快流量）

**字数：** 140-500字
**结构：** 观点先行→快速展开→留悬念
**发布时间：** **12:00** 或 **18:00** 或 **21:00**
**引流：** 微博允许直接挂公众号链接（网页链接），也可以写"搜xxx"
**免费流量：** 参与「超级话题」+ 免费「粉丝头条」试用

## 五、内容质量门控

每篇写完后自检：
1. **视角刁钻吗？**——换普通人，他会不会觉得"这我没想到"？
2. **有画面吗？**——闭眼能不能看见场景？不能就重写第一段。
3. **冷幽默有吗？**——自己读一遍，有没有地方让你嘴角动一下？
4. **密度够吗？**——删掉所有"的""了""吧"，删到不能再删。
5. **引流自然吗？**——像"顺口提了一句"还是像"广告插入"？

## 七、引流避坑指南

| 平台 | 可以做的 | 不能做的 |
|------|---------|---------|
| 公众号 | 文章末尾引导"搜xxx"，菜单栏放微信 | 外链泛滥、诱导分享 |
| 知乎 | 个人简介写公众号名，文章末尾引导搜索 | 放二维码、微信号、外链 |
| 小红书 | 评论区"扣1私信"→私信引导→微信 | 正文放微信/二维码/链接 |
| 微博 | 放公众号链接，搜xxx | 群发广告、频繁私信 |
