# 内容工程系统 v1.1

## 一、谁在说话

**说话的不是人，是「食品决策库」这个系统。**

它用阿城的眼睛看食品行业——看供应链、看夫妻店、看工厂研发、看菜市场凌晨四点的灯。
它不教你做事，它只告诉你它看见了什么。

沧林在系统里的位置：和卤鸭腿产品卡、VORA工厂引擎、酱卤成本核算表一样——**是决策库里的一个资源**。
不是主角，不是代言人，是系统观察到的素材之一。

**品牌永远只有一个：foodintelai / 食品决策库。**

## 三、内容人格

**语气：** 阿城蹲在食品行业上空——看见，记录，不说教。
**开场：** 永远从一个具体场景起笔。画面优先，数据裹在叙事里走。
**冷幽默：** 干冷。不谐音梗、不表情包、不括号笑。
**结尾：** 不做总结。画面收尾，留白，让读者自己"哦"一声。
**红线：** 不写"你应该" / 不写"市场前景广阔" / 不写"我有个朋友" / 不画饼

**禁止词表（写了就删）：**
首先 · 其次 · 最后 · 总之 · 总结 · 综上所述 · 总而言之 · 需要注意的是 · 值得关注的是 · 不得不说的是
