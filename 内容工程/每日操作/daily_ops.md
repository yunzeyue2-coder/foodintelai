# 每日操作

## 开始前先答三问

```
1. 今天哪个信号最强？
   → ________（评分：_）
   
2. 这个信号对应什么决策？
   → ________
   
3. 这个决策出什么内容？
   → L□ 原子判断（300-800）
   → L□ 案例文章（1200-2500）
   → L□ 方法论（2000-4000）
```

答不出来不写。

---

## 流水线

```
① 信号扫描 + 评分 → 入信号层
② 决策中枢更新（今日Top3/押注/暂停）
③ 写内容（按三级：L1/L2/L3）
④ 嵌工具入口
⑤ 分发（公众号/知乎/小红书/微博）
⑥ 用户行为记录
⑦ 数据回收入库
⑧ 复盘
```
