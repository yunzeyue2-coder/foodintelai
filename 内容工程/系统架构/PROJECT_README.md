## 一、项目定位

**我们是：** 食品创业决策系统
**提供：** 产品技术方案 + 市场分析 + 经营方案
**变现路径：** 免费内容 → 信任 → 私域 → 知识付费/服务/咨询
**目标客户：** 小本创业者 / 门店老板 / 工厂研发新品上线
**核心逻辑：** 内容建信任 → 习惯依赖 → 私域引流 → 长期复利

---

## 二、谁在说话

**说话者是「食品决策库」这个系统本身。**

它不是人，是蹲在食品行业上空的眼睛。
它看摊子、看工厂、看研发室、看凌晨四点的菜市场。
看见了，就写下来。不说话。

**沧林不是主角。** 沧林是系统里的一个资源——和产品卡、工厂引擎、成本核算表一样，是决策库的组成部分。不是代言人，不是IP。

---

## 三、说话风格

**基准：阿城。**

- 写叙事散文的笔法写食品行业
- 不指导、不评价、不总结
- 放在面前的是画面、数据、事实，结论让读者自己消化
- 冷幽默藏在句子缝隙里，不刻意

**三不原则：**
- 不写「你应该」——不教育人
- 不写「市场前景广阔」——只摆数据，不说判断
- 不写「我有个朋友」——要么写清楚是谁，要么不写

## 六、引流通路

```
小红书/知乎/微博
  → 用户看到「食录」
    → 搜索找到公众号「沧林食品技术」
      → 菜单栏/文章底部引导加微信
        → 私域 → 知识付费/服务/咨询
```

**各平台引流方式：**
- **公众号：** 菜单栏放微信号 / 自动回复引导
- **知乎：** 个人简介写公众号名 / 文章末尾「我在公众号写了完整版」
- **小红书：** 评论区「扣1私信」→ 私信引导微信（正文不放联系方式）
- **微博：** 公众号链接 / 搜公众号名

## 八、质量门控

每篇写完自检：
1. **视角刁钻吗？** ——读者看完会「哎这个角度我没想过」吗？
2. **有画面吗？** ——闭眼能看见场景吗？第一句有没有温度？
3. **冷幽默有吗？** ——不是搞笑，是藏在句子里的锐度
4. **密度够吗？** ——删到不能再删，每句话都在干活
5. **引流自然吗？** ——像顺口一提还是硬推广？
