# 内容架构细则

## 一、专栏模板总纲

### 共同规则

**每篇文章必须包含：**
1. **一个具体场景开头**——不要引言、不铺垫，第一句就给画面
2. **数据裹在叙事里走**——不单独列表，数据是故事的一部分
3. **结尾留白**——不写总结，用画面或一句对话收尾

**禁止词（写了就删）：**
首先 · 其次 · 最后 · 总之 · 总结 · 综上所述 · 总而言之 · 需要注意的是 · 值得关注的是 · 不得不说的是 · 下面我们来看 · 接下来 · 除此之外

**图片规则：**
- 公众号：头图1张（有质感的食物/工作场景） + 正文2-3张（工艺/食材/人物） + 结尾1张（字迹/工牌/工具）
- 小红书：封面1张（垂直/暖调/食物特写） + 正文5-8张（细节/场景/截图）
- 知乎：同公众号配图，可额外加1-2张数据示意图
- 微博：1张图即可（或纯文字）

## 二、观察笔记 · 专栏模板

**平台：** 公众号
**字数：** 1200-2000
**频率：** 周2-3篇

**结构模板：**

```
【开头·一个画面】  （150-300字）
写一个人、一个摊、一间厨房、一个瞬间。
不交代背景，不解释前因。
就是一个画面。

【中间·展开】  （800-1200字）
从画面里带出信息：
  - 这个人在干什么
  - 干什么的背后是什么工艺/配方/市场逻辑
  - 数据藏在叙事里：成本、利润、时间、温度
不分类、不标序号、不写小标题——散文的节奏走。

【结尾·留白】  （100-200字）
回到开头那个画面，或者换一个画面。
不总结、不升华、不画句号。
读者自己消化。
```

**配图：** 3-5张

## 三、味道拆解 · 专栏模板

**平台：** 公众号 + 知乎专栏
**字数：** 公众号版2000-2500 / 知乎版2500-3500
**频率：** 周2篇（一篇从观察笔记扩展，一篇独立）

**结构模板：**

```
【开头】  （200-300字）
一个具体的场景引出这个品类的主角。
不写「今天我们来聊聊XX」。
写「凌晨四点，市场上XX的摊位已经排了七八个人。」

【技术层】  （400-600字）
配方结构、工艺关键点、温度曲线。
数据嵌在叙述里——「一斤XX煮完剩六两二，失水率38%」不单独列表。
如果必须有参数，一段一个数据，不要并排出现。

【市场层】  （300-500字）
这个品类现在谁在买、谁在做、成本结构、利润模型。
用故事包装数据——「老板算了一笔账：一斤肉、八两水、一两酱油、三片姜。」

【经营层】  （300-400字）
摆摊/开店/工厂的落地关键。
三句话能说明白的事不用一段。

【结尾】  （100-200字）
回到开头或者一个相关的画面。
不总结。
```

**配图：** 3-5张（头图+工艺图+场景图+收尾图），知乎版可多加1-2张数据图

## 四、水面下 · 专栏模板

**平台：** 公众号 + 知乎专栏
**字数：** 1500-2500
**频率：** 周1篇

**结构模板：**

```
【开头】  （200-400字）
一件小事，引出水面下的暗流。
不写「今年XX行业发生了重大变化」。
写「上个月去XX市场，一个干了十年的摊位关了。」

【暗流层】  （600-1000字）
人群看法a：明面上大家都在说什么
人群看法b：但数据和事实指向什么
反差——别人看到的和我看到的不一样。

【技术/数据层】  （300-500字）
用一两个具体的数据或者工艺细节，证明这个反差不是错觉。
不堆数据，一个数据说明一个问题。

【结尾】  （100-200字）
不挑明结论。画面收尾。
```

**配图：** 2-4张

## 五、小红书 · 笔记模板

**平台：** 小红书
**字数：** 300-600
**频率：** 每天1条

**结构模板：**

```
【标题】15字以内
反常识 / 具体数字 / 画面感
不用感叹号，不用问号，不吃惊。

【正文】
4-8行，每行就是一句话。
口语化但不轻浮，冷幽默夹干货。
第一句给画面，最后一句留白。
不写「求关注」「点赞收藏」。

【标签】
5-8个：1个大词 + 2-3个中词 + 2-3个长尾词
```

**配图：** 6-9张
- 封面：高质感食物特写（暖调/暗调/手工感）
- 细节图：工艺过程/食材特写/锅碗工具
- 文字图：配方/数据截图
- 场景图：工作台/市场/厨房

## 六、微博 · 笔记模板

**平台：** 微博
**字数：** 140-500
**频率：** 每天1-2条

**结构模板：**

```
【观点句】30字以内
最犀利的那句话放在最前面。

【展开】50-200字
一段话展开，提供背景或数据。

【引流】一句
「搜公众号：沧林食品技术」
```

**配图：** 0-1张
