麻辣烫·冒菜蘸料干碟体系

油碟 · 干碟 · 双拼 · 麻酱蘸料 — 增项价值·提升客单·火锅感
🫒 油碟🌶️ 干碟🥢 双拼🫘 麻酱蘸料💰 增项
🔥 一句话定义
蘸料和干碟是麻辣烫/冒菜的"增值项"——不是必须的（大部分麻辣烫店不提供蘸料），但有蘸料=把一碗20元的麻辣烫吃出了"一人食火锅"的体验感。好蘸料的价值：让顾客多花3-5元加一份料、发朋友圈、回头。

麻辣烫/冒菜的蘸料分三大类：油碟（香油+蒜泥+蚝油——解辣增香）、干碟（辣椒面+花椒面+花生碎+芝麻+盐+味精——重口味人群最爱）、麻酱蘸料（北方火锅风格——醇厚浓郁）。
💡 蘸料/干碟的商业价值
要不要提供蘸料？算一笔账
不提供蘸料：出餐快（省去顾客自己调蘸料的时间）、省成本（每碗省0.5-1元）、操作简单。但顾客觉得"就是一碗麻辣烫"——没啥特别的。

提供蘸料：
· 每碗增加成本约0.3-0.8元（油碟0.5元/份、干碟0.3元/份）
· 客单价提升3-8元（加一份肉+一份蘸料=多收5-10元）
· 顾客体验升级——有蘸料=更像火锅=更愿意拍照发朋友圈
· 差异化——你附近3公里10家麻辣烫店，9家不提供蘸料，你是那1家，你就赢了

结论：建议提供蘸料，但不是免费（因为免费了成本控制不住）。蘸料套餐化：加3元得油碟+干碟双拼、加5元得油碟+干碟+饮品。顾客觉得"就多3块钱，试试"——但这3块钱是纯利润（成本不到0.8元）。

🫒 ① 油碟（解辣·增香·最经典）
简介
油碟是四川火锅/冒菜的经典标配蘸料。核心成分就三样：香油（芝麻油）+ 蒜泥 + 蚝油。香油裹在食材表面形成一层"保护膜"——减少辣味对口腔的刺激（解辣）、增加食材的光泽和香味、同时降低食材温度（一口吃下去不烫嘴）。油碟是麻辣烫/冒菜中最推荐提供的蘸料——成本低、效果好、顾客认知度高。
油碟配方（每份·成品约40g）
最基础的版本，可根据顾客需求加料
芝麻油（香油）20g
蒜泥10g
蚝油5g
醋3g（可选）
葱花2g
香菜2g
油碟进阶方案
给顾客的自助油碟台配置：
基础配置（3样）：香油壶 + 蒜泥 + 蚝油
进阶配置（6样）：香油 + 蒜泥 + 蚝油 + 醋 + 葱花 + 香菜
豪华配置（8样）：香油 + 蒜泥 + 蚝油 + 醋 + 葱花 + 香菜 + 小米辣 + 花生碎

⚠️ 注意：油碟的香油要用纯芝麻油，不要用调和油。纯芝麻油批发价约25-40元/斤，每份成本约0.3-0.5元。如果用调和油（5-10元/斤）做油碟——顾客一口就吃出来是"假香油"，体验感大打折扣。
🌶️ ② 干碟（重口味·年轻人最爱）
简介
干碟在麻辣烫/冒菜中不是标配——但在年轻客群（尤其15-30岁）中非常受欢迎。把烫好的菜在干碟里蘸一下再吃——表面裹满辣椒面+花椒粉+花生碎，口感层次极丰富。干碟适合重口味、喜欢"又辣又香又麻"的客群。冒菜店加一份干碟=客单价能提3-5元。
干碟配方（每份·成品约15g）
麻辣方向·通用型
辣椒面（二荆条+子弹头1:1）5g
花椒面（红花椒炒香磨粉）2g
熟花生碎4g
熟白芝麻2g
盐1g
味精0.5g
白糖0.5g
干碟的两个变体方向
① 特辣版（适合红油汤底）：辣椒面7g + 花椒面3g + 花生碎3g + 芝麻2g——魔鬼辣方向。
② 香辣版（适合骨汤白汤）：辣椒面4g + 花生碎5g + 芝麻3g + 盐1.5g + 孜然粉1g——香大于辣。

干碟制作要点：
· 辣椒面建议自己打（干辣椒炒香后打粉）——买的成品辣椒面很多掺了辣椒精/色素
· 花椒必须炒香再打粉——生花椒打粉只有"麻"没有"香"
· 每个干碟建议配一个小碟子装——让顾客自己蘸，不要一次性全倒进碗里（有些顾客不喜欢太重的干料）
· 干碟的保质期：密封干燥保存1个月没问题。但花生碎容易受潮变软，建议少量多次制作
🫘 ③ 麻酱蘸料（北方火锅风格·适配骨汤白汤）
简介
麻酱蘸料=把北方涮羊肉的麻酱蘸料搬到麻辣烫上。适合骨汤白汤麻辣烫——食材从骨汤里捞出来→蘸一下麻酱→入口是骨汤的鲜+麻酱的醇厚。麻酱蘸料在北方市场接受度极高（北京/天津/河北/东北），但在南方市场谨慎使用（麻酱不是南方人的日常调味品）。

调好的芝麻酱30g

水（调稠度）适量
商业建议
麻酱蘸料不是必须的——它是"加分项"不是"基础项"。如果你的店在北方（麻酱消费基础好）且你做的是骨汤白汤麻辣烫——提供麻酱蘸料会有很好的效果。如果在南方/做红油麻辣烫——麻酱蘸料可能水土不服，建议先小范围试一下。
🎯 蘸料+汤底搭配参考
汤底类型推荐蘸料组合推荐理由
红油底料（麻辣方向）油碟（解辣必备）+ 干碟（重口味可选）油碟解辣增香、干碟再加一层麻辣——先蘸油碟再蘸干碟，口感超丰富
骨汤白汤（北方方向）麻酱蘸料（标配）+ 油碟（可选）麻酱+骨汤=绝配。油碟适合想清爽一点的顾客
番茄底料（不辣方向）油碟（少香油多蒜泥）或 不配蘸料番茄汤本身味型鲜明，蘸料反而会掩盖番茄味。最多配个清淡油碟
藤椒底料油碟（少蚝油）藤椒的清香味比较淡雅，油碟不要放太多调料抢味
冒菜（干拌/带汤通用）干碟（标配）+ 油碟（可选）冒菜最像"单人火锅"——干碟+油碟=火锅标配蘸料组合
💡 蘸料区的"火锅感"设计

如果你想让顾客觉得"我吃的不是一碗麻辣烫，是一人食火锅"——把蘸料区做成火锅店的样子：小碗+小碟+多种调料自助。投入不超过500元（小料台+一次性小碗+调料壶），但顾客的感知价值能从"这碗麻辣烫值15元"变成"这碗值25元"。

⚠️ 蘸料·干碟核心铁律
  1. 蘸料不是免费的（除非你把它算进了售价里）。提供蘸料=增加成本。如果免费提供，顾客会"拿很多、用不完、浪费掉"——每碗成本从0.5元涨到1.5元。正确做法：套餐化（加3元得双拼蘸料）、或做成自助小料台（加2元畅用）。
  2. 干碟不要提前混合——让顾客自己混。很多店觉得"我帮你配好干碟端上来"很方便——但顾客更享受"自己蘸、自己调"的参与感。干碟建议提供调配好的干粉碗+顾客自己蘸着吃。
  3. 油碟的香油必须纯。用调和油/香精勾兑的"香油"——顾客吃一口就倒了胃口。纯芝麻油每份成本0.3-0.5元，比调和油贵一倍，但这笔钱不能省。油碟的核心卖点就是"香"，不香=没有存在的必要。
  4. 蘸料是"体验升级"不是"必备项"。如果你的店定位是"快吃快走"（翻台率高、客单价低），蘸料可能增加出餐时间、降低翻台率。如果你的店定位是"慢慢吃、聊聊天"（客单价高、翻台率低），蘸料是必选项。
  5. 不要提供超过8种蘸料选择。选择多了顾客反而困惑——"这么多调料我该放哪些？"火锅店几十种调料是因为火锅本来就是"慢慢吃"，但麻辣烫是快餐。3-5种蘸料选择是最优解：油碟+干碟+麻酱+醋+辣椒油。
  6. 蘸料用完后一定要冷藏。油碟的蒜泥常温放2小时就开始变质（发酸）。干碟受潮后发硬结块。麻酱蘸料常温超过4小时表面会发干、结皮。每天收摊后蘸料全部入冰箱——这是食品安全底线。
