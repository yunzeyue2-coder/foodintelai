▶ 一句话定义
夫妻肺片是中国凉菜市场单品规模最大的牛肉杂拌菜，以牛心、牛舌、牛肚、牛肉等卤制后切片，配以秘制红油、花生碎、香菜等拌匀，麻辣鲜香、口感丰富。覆盖熟食店、堂食凉菜、外卖、预包装四大场景，是川卤在全国的绝对爆款。

08 技术难点
1. 牛杂去腥不到位
牛心、牛舌等内脏异味重，处理不好毁整盆。
→ 用面粉+盐反复搓洗2遍，白酒+姜片浸泡1小时，焯水时加花椒、白芷。
2. 红油只辣不香
市面很多用辣椒精+色素，入口辣喉没有复合香气。
→ 三种辣椒（二荆条+子弹头+灯笼椒）按4:3:3比例，菜籽油分两次淋入，焖24小时出香。
3. 牛杂卤过头没嚼劲
卤制时间太久，牛肚牛心变软烂失去口感层次。
→ 牛肚卤40分钟、牛心60分钟、牛舌50分钟，分别下锅，关火再焖20分钟。
4. 拌后出水严重
红油拌完几分钟就析出水分，变成水垮垮的红油汤。
→ 卤制后彻底沥干水分，切片后放冰箱冷藏30分钟再拌；红油中加入少量花椒面吸湿。
5. 花生碎返潮变软
花生碎拌入后很快不脆，影响口感。
→ 现吃现撒花生碎，预包装产品用独立小包花生，上桌前由顾客自己加。
6. 红油分层油腥味重
炼油时火候不对，油脂氧化产生腥味。
→ 菜籽油烧到240℃去生味，降温至180℃再下香料，全程小火慢炸。
7. 切片厚薄不均
手工切片差异大，厚片不入味，薄片易碎。
→ 牛杂卤制后压实冷藏定型，用切片机或锋利菜刀切2~3mm薄片。
8. 保质期极短
现拌夫妻肺片冷藏不超过24小时，预包装很难解决。
→ 肉片真空单独包装，红油包+花生包+蔬菜包分装，食用前混合，冷藏可保存7~10天。
9. 卤水管理复杂
多种内脏混合卤制，卤水容易腥臭。
→ 内脏单独一锅卤水，不与牛肉制品混用，每天过滤煮沸。
10. 麻辣平衡难把握
麻度和辣度的比例不同地区偏好差异大。
→ 红油和花椒油分开调配，售卖时根据顾客要求“加麻”“加辣”，标准化基础底味。
09 常见误区 （16条）
×夫妻肺片里真的有肺片 → √ 传统做法不含肺，主要用牛心、舌、肚、牛肉，名字是谐音“废片”。
×红油越红越辣越好 → √ 颜色主要来自辣椒红和油脂，辣度要和香度平衡，过辣掩盖肉香。
×所有内脏可以一起卤 → √ 不同内脏厚度和卤制时间不同，要分批次下锅，否则有的烂了有的没熟。
×卤水越陈越香 → √ 内脏卤水极易变质，每周必须重新调新卤，不能长期保存。
×夫妻肺片只能堂食不能外卖 → √ 采用“肉+红油+花生”分装，外卖30分钟口感影响可控。
×花生碎可以用现成的 → √ 现炸花生米拍碎，香气和脆度远超袋装熟花生。
×红油一次做很多慢慢用 → √ 红油放置超过2周香味衰减，建议每周做一次小批量。
×拌菜时油越多越香 → √ 油多盖住肉的质感，适量红油加卤水原汤融合才挂味。
×用便宜的牛杂代替 → √ 便宜杂碎（气管、食管）口感差，顾客吃一次就流失。
×只需要辣椒和花椒就够了 → √ 十三香、豆豉、芝麻酱复合底味才是老味道的灵魂。
×夫妻肺片不能冷冻保存 → √ 卤好的肉片可以真空冷冻，解冻后切片拌制，口感损失10%可接受。
×拌菜不用加白糖 → √ 少许白糖提鲜、中和辣味，让红油更醇厚，是川式凉菜的秘密。
×夫妻肺片是夏季产品 → √ 全年稳定，冬季搭配热菜同样受欢迎，下酒刚性。
×只要把料拌进去就行，不用顺序 → √ 先放固体调料（盐、糖、花椒面），再放液体（卤水、生抽、红油），最后放花生、芹菜。
×预包装夫妻肺片没有市场 → √ 料包分离式产品在电商平台月销过万，但还原度是关键。
×夫妻肺片只能牛杂做 → √ 鸡肉、猪杂版本在部分区域也有市场，可作为低价引流款。
