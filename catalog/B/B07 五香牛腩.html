▶ 一句话定义
五香牛腩是兼具软糯口感+高利用率的酱卤牛肉品类，以牛腹部五花腩为主料，五香卤制后肉中带筋、肥瘦相间，覆盖熟食凉菜、牛腩面浇头、火锅涮品、预制菜四大场景，是B端餐饮用量最大的牛肉单品之一。

07 技术路线图
五香牛腩核心工艺路线
├─ 传统小火慢卤 — 耗时2.5~3h，软糯入味，适合精品熟食
├─ 高压快速卤制 — 20~30分钟出品，效率高，适合批量B端
├─ 先炒后卤路线 — 牛腩煸炒出油再卤，更香不腻
└─ 预制菜标准化工艺 — 切块→焯水→定量卤制→速冻，供应连锁餐饮

出品率与成本
生牛腩 → 焯水缩水15~20% → 卤制缩水20~25% → 自然出品率约55~60%
保水工艺出品率可达68~72%，但肉质偏嫩失去嚼劲
坑腩自然出品率55%左右，售价75~85元/斤；混合腩出品率60%，售价55~65元/斤
08 技术难点
1. 肉质发柴发硬
牛腩部位结缔组织多，炖煮不够软烂就嚼不动。
→ 小火卤制2.5小时以上，用筷子能轻松扎透为准。高压锅压20~25分钟自然泄压。
2. 肥油过多发腻
牛腩脂肪含量高，卤后油腻感重。
→ 生牛腩先冷水浸泡1小时，再焯水撇净浮油；卤制后冷藏撇去上层凝固牛油。
3. 形状散碎不成块
过度炖煮或切太小导致卤后变成碎肉渣，卖相差。
→ 切5~6cm大块卤制，卤完再改刀成标准块（3cm左右），先卤后切更完整。
4. 五香味渗透不足
牛腩块厚，香料味道只在外层。
→ 牛腩焯水后用竹签扎孔，卤制时间不低于2小时，关火再浸泡过夜。
5. 出品率波动大
不同牛腩部位和脂肪含量导致出品率从50%~65%不等。
→ 固定供应商和部位（坑腩或谷饲腹腩），每批称重生熟重，按实际出品率调价。
6. 卤水发酸变质
牛腩血水油脂多，卤水易坏。
→ 每天卤完必须过滤料渣、撇净浮油，煮沸后冷藏。卤水每3天重新调整香料。
7. 色泽发灰无光泽
牛腩卤后颜色暗沉，缺乏红亮酱色。
→ 用糖色+红曲米上色，卤制后期加老抽调色。出锅后刷一层卤油增亮。
8. 预包装冷藏后变硬
卤牛腩冷藏后脂肪凝固，口感变硬。
→ 预包装产品需含适量卤汤（30%汤汁），复热后口感恢复。零售建议带汤售卖。
9. 腥味残留
牛腩血水重，处理不当有膻味。
→ 冷水浸泡2小时换水两次，焯水时加高度白酒和姜片，白芷是去牛腥关键。
10. 竞争同质化
五香牛腩家家会做，没有差异化。
→ 开发不同风味（番茄五香、咖喱五香）、做浇头专用小包装、主打无添加鲜卤。
09 常见误区 （16条）
×牛腩越瘦越好 → √ 带适量脂肪的坑腩卤后才香软，纯瘦肉牛腩口感发柴。
×卤牛腩时间越短越Q弹 → √ 牛腩必须长时间炖煮才能软化结缔组织，否则咬不动。
×所有部位都适合五香卤 → √ 坑腩（肋条）最佳，其他部位口感差异大，尽量选坑腩或爽腩。
×牛腩利润不如牛腱高 → √ 牛腩进价比牛腱低15~20%，售价仅低10%，毛利反而更高。
×卤牛腩一定要用老卤 → √ 牛腩油脂多，老卤重复使用易变质，建议每次加新汤调整。
×切小块卤制更入味 → √ 小块卤容易碎成渣，大块卤再切更保形。
×卖五香牛腩不用考虑B端 → √ B端面馆、快餐店用量是零售的10倍以上，忽视B端等于丢大市场。
×冷冻牛腩不如鲜牛腩 → √ 进口冷冻牛腩排酸后反而更易软烂，价格稳定。
×大火收汁更入味 → √ 大火会让牛腩表面变硬，全程微开盖小火保持似开非开。
×卤牛腩可以不用焯水 → √ 不焯水的牛腩血沫和异味会污染卤水，必须冷水下锅焯透。
×只做五香牛腩就能养活一家店 → √ 牛腩单品毛利率虽好，但需搭配粉面、米饭等主食场景，单独熟食店需配其他产品。
×真空包装即食牛腩最好做纯肉 → √ 带30%卤汤的牛腩复热后口感更佳，纯肉干硬。
×牛腩不需要考虑香料去腥 → √ 白芷、草果、花椒是核心去腥组合，不能省。
×卤牛腩价格越便宜越好卖 → √ B端客户追求稳定品质，便宜牛腩碎肉多，反而流失客户。
×牛腩不能做凉菜 → √ 五香牛腩冷却后切片可做凉菜拼盘，配蒜醋汁风味独特。
×预制菜牛腩可以不加添加剂 → √ 保质期6个月以上的需添加符合国标的抗氧化剂和复配防腐剂，否则风味劣变快。
