⚠️ 最大风险
💀粉条口感翻车：红薯粉掺假（加木薯/玉米淀粉）会导致发硬不Q弹。纯红薯粉呈暗褐色半透明，沸水煮5~8分钟不糊汤才是好粉。批发价8~15元/kg，别贪便宜买杂牌。
🦴骨汤品质不稳定：酸辣粉的灵魂在汤。熬汤必须冷水下锅→大火撇沫→中小火微沸4h（不可大滚否则汤色发浑）。节省成本可用浓缩骨汤膏（20元/kg勾兑100L），但口感差一个档次。
⚖️酸辣比例失衡：醋:辣椒油≈1:0.8是黄金比例。醋多了发涩，辣多了烧胃。不同地区的顾客接受度不同，建议设"微辣/中辣/重辣"三档。
🌡️出餐速度瓶颈：预制湿粉只能冷藏保存12小时，不可过夜。粉条泡发时间没控制好→出餐高峰期卡住。建议按销量预估预制，每锅少量多次。
📦外卖体验差：粉条在汤里泡10分钟就发胀变软。外卖必须汤粉分离包装，顾客收到后自己泡，否则差评率极高。
🔪 核心工艺：酸辣粉
选品标准：纯红薯淀粉≥90%·直径1.5~2.5mm·暗褐色半透明·沸水煮5~8min不糊汤
品牌参考：双塔、方中山、龙须（川渝常用）——批发价8~15元/kg
冷水浸泡（推荐）：干粉入冷水4~6h（夏季3h）→变软无硬芯·500g干粉→约1.8~2kg湿粉
温水速发（补货用）：40~50℃温水40~60min
沸水焯烫（最Q弹）：水开下粉煮1~2min→立即过凉水（损耗大）
⚠️ 关键：预制湿粉拌入少许熟油防粘连·冷藏保存≤12h·单碗用量干粉80~120g(湿粉200~300g)
原料：猪筒骨2.5kg（劈开·冷水浸泡30min去血水）+ 鸡架1.5kg + 姜片80g + 葱段100g + 料酒50ml + 白胡椒粒10g + 水12L→收至10L
制作：骨头冷水下锅→大火煮沸撇净浮沫→转中小火保持微沸（不可大滚）→熬4h至汤色奶白→过滤取汤
商用替代：纯骨汤成本最高·浓缩骨汤膏20元/kg勾兑100L（成本降40%）·浓汤宝次之·清水+骨味香精不推荐
单碗用量：250~350ml骨汤
碗底料（单碗）：蒜末8~10g + 姜末3~5g + 熟白芝麻5g + 辣椒面8~12g（二荆条:子弹头=7:3）+ 花椒粉2~3g
激油：菜籽油40~50ml烧至200℃泼入碗底料 → 搅匀
调酸辣：保宁醋25~35ml + 生抽15ml + 老抽5ml（调色）+ 白糖5~8g + 白胡椒粉2g + 香油3~5ml + 红油辣椒20~30ml + 盐3~5g
醋:辣椒油=1:0.8：酸辣均衡主流配比。偏酸1:0.5·偏辣1:1.2·重口味1:1.5
总酸辣汁量/碗：约55~70ml（含红油）
核心比例：菜籽油2500ml（10份） + 二荆条辣椒面（细粉）250g（1份·主香色） + 子弹头辣椒面（粗粒）100g（0.4份·主辣）
辅料：白芝麻80g + 花椒粒15g + 香叶5片 + 八角4颗 + 桂皮1段(约5g) + 草果2颗(拍破) + 姜片40g
炼油：油烧至180~200℃→下姜片+香料炸香→捞出→油温降至160℃泼入一半辣椒面→120℃泼入剩余辣椒面
关键：静置24h后使用·颜色和香气最佳·一次做5L成本降30%
原料（10碗份）：五花肉末300g（三肥七瘦·手切） + 碎米芽菜100g + 郫县豆瓣酱40g（剁细）+ 姜末20g + 蒜末15g + 料酒20ml + 生抽20ml + 五香粉3g + 白糖5g + 油50ml
炒制：热锅凉油→下肉末中小火煸炒至出油微焦黄→下姜蒜末→加豆瓣酱炒出红油→加芽菜翻炒→烹料酒→加生抽+五香粉+糖→加少量水(50ml)小火收汁
单碗用量：30~40g臊子
降本技巧：可掺20%豆干丁，增加口感层次的同时降低成本
💡 酸辣粉的核心竞争力=骨汤的厚度+酸辣的平衡感+粉条的Q弹度。这三个维度中有一个差，顾客就不会回头。

⚠️ 出餐流程（单碗45~60秒）：①碗底放蒜姜+芝麻+辣椒面→浇热油激香 ②加醋+生抽+老抽+糖+盐+白胡椒+红油 ③浇滚烫骨汤300ml搅匀 ④放入泡好的湿粉250g ⑤码上肉臊子35g+花生碎12g+榨菜15g+葱花5g+香菜5g ⑥出餐前再淋一勺红油增色

⚠️ 翻车解决方案
粉条不Q弹：①红薯粉掺假（加木薯淀粉）→换纯红薯粉 ②泡发时间不够或过久→冷水4h刚好 ③煮过头→沸水焯烫≤2min
汤底不够鲜：①熬汤时间不够→至少4h ②骨头没劈开→骨髓没出来 ③汤色发浑→火太大，保持微沸不是大滚
酸辣不协调：①醋太多→加骨汤稀释或加糖中和 ②辣味苦→辣椒炸过头了，激发油温控制在160℃以内 ③酸味层次不够→保宁醋换香醋试试
肉臊子干柴：①火太大→中小火慢炒 ②肥肉太少→三肥七瘦，五花肉最佳 ③收汁太干→留一点汤汁
红油不红不香：①辣椒品种不对→二荆条主香+子弹头主辣 ②没静置→必须静置24h ③油温过高→160℃/120℃分两次泼
