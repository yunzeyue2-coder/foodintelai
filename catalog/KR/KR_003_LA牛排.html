⑥ 腌制工艺
核心逻辑：LA牛排的灵魂是腌制——酱油底+水果软化（梨/苹果/奇异果）+ 甜味平衡。不腌=普通烤牛排。
  1. 泡血水：牛排骨冷水浸泡30分钟去血水·中间换一次水
  2. 拍打：用肉锤或刀背轻轻拍打（不可太重·肉会散）
  3. 腌制（关键）：酱油+梨汁/苹果汁+糖+蒜末+姜末+香油+黑胡椒·冷藏腌制4-6小时（不超过12小时）
  4. 回温：烤前30分钟取出回温至室温
  5. 烤制：烤盘/铁板中高温·每面1-1.5分钟·表面微焦即可·不可烤久（会老）
📋 LA牛排腌制汁配方（批量50份）
酱油底：酱油1000g + 水500ml + 味醂（미림）300g
水果软化：梨（或苹果）500g打泥 + 奇异果200g打泥（奇异果酶解效果最强·不可过量否则肉会散）
甜味调料：白糖200g + 麦芽糖稀150g + 蜂蜜100g
香料：蒜末300g + 姜末50g + 洋葱末200g + 黑胡椒粉30g
油脂：香油100g + 色拉油50g
操作：所有材料混合搅匀→放入牛排骨→戴手套抓匀→密封冷藏4-6小时→每2小时翻一次
成本：腌制汁约2-3元/份（摊到排骨上）
保存：腌制汁可提前做好·冷藏3天内用完
