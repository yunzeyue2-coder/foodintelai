⑥ 工艺标准 · 从解冻到上桌
  1. 解冻：冷藏室0-4℃自然解冻12小时·不可微波或温水急解冻（损失汁水）
  2. 修整：修去边角不规则脂肪·保证每块厚度均匀·去皮（部分门店保留薄皮增脆感）
  3. 切制：厚切1.5-2cm·每块150-200g·刀口垂直于肌肉纹理·切完不按压
  4. 摆盘：每份8-10片·平铺不叠放（美观+易烤）·垫生菜叶或紫苏叶
  5. 蘸料搭配：标配쌈장（包饭酱）+ 蒜片+ 青辣椒圈+ 生菜
📋 包饭酱（쌈장）配方 · 烤肉标配
韩式包饭酱（批量100份）：韩式大酱（된장）500g + 韩式辣椒酱（고추장）300g + 蒜末150g + 洋葱末200g + 青椒末100g + 糖80g + 麦芽糖稀100g + 香油60g + 熟芝麻50g + 水200ml → 小火搅匀煮开即可
简化版（家庭/小摊）：韩式大酱3:辣椒酱2:蒜末1:糖0.5:香油0.3:芝麻0.2 比例混合
成本：包饭酱约2-3元/份（含配菜）
保存：冷藏7天·冷冻30天
🧂 烤制撒料（粗盐/蘸盐）
韩式经典（三陟市吃法）：粗盐1份 + 香油2份 — 五花肉烤好蘸粗盐再蘸香油·最原味
韩式黑椒版：粗盐3份 + 现磨黑胡椒1份 — 混合装小碟·顾客自行蘸取
中式改良版（烧烤摊主流）：孜然粉5份 + 辣椒面3份 + 熟芝麻1份 + 味精0.5份 + 糖0.3份 — 混合均匀
成本：撒料约0.2-0.5元/份

⑧ 创业决策
💰 自切还是买切好？建议自切（买整条五花肉自己切）。冷冻五花肉整条进货比切好片成本低30-40%。唯一需要的是切片机（手动切片机300-500元·电动2000-4000元）。日售20份以上的门店建议购买电动切片机。
🎯 风险控制
· 五花肉价格波动大（猪周期），建议签季度锁价协议
· 冻肉解冻后必须在48小时内用完，不可反复冻融
· 厚切vs薄切：厚切更有"仪式感"但出餐慢（烤5-7分钟）·薄切出餐快（2-3分钟）但单价低
· 地摊版建议做薄切（翻台率优先）
