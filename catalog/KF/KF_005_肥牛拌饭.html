肥牛拌饭（右下·高复购走量款）
石锅拌饭（右上·传播型）

矩阵定位：肥牛拌饭偏右下——复购高但传播力一般。它的角色不是"让人拍照"，而是"让人吃饱"。
和石锅拌饭形成不同功能：石锅拌饭是"仪式感主食"，肥牛拌饭是"效率主食"。

⑥ 工艺配方 · 肥牛拌饭（主推款）
出品规格：米饭210g + 肥牛130g + 金针菇30g + 洋葱丝70g
调味：肥牛汁150g + 老抽2g + 胡椒粉0.2g · 撒香葱+白芝麻

🍚 米饭标准

用米：东北珍珠米或五常大米（圆粒米），不要用南方长粒米——圆粒米粘性好，拌饭时能裹住酱汁。
混合比例：大米4 : 糯米1（糯米增加粘性，让米饭能"抱住"肥牛汁）。进阶版可加大黄米10%（增加香气和颗粒感）。
淘洗：淘洗至水清（约3-4次），浸泡30分钟再蒸——浸泡后的米蒸出来更透。
米水比：1 : 1.1（商用蒸饭柜）或 1 : 1.2（电饭煲）。
设备：商用蒸饭柜（电蒸箱）最佳，一次蒸20-40斤米饭。没有蒸饭柜用大电饭煲也行，但出餐效率低。
每份：210g（熟饭），用电子秤称量，不要凭手感。
保温：蒸好的米饭放在保温柜（60°C）保存，超过4小时未用完的弃掉——米饭放久了水分蒸发变干硬。

🥣 载具标准

推荐载具：韩式铜碗（φ14-16cm）或日式丼碗（陶瓷）。
不要用：石锅（肥牛拌饭不是石锅拌饭，不需要锅巴）、浅盘（汤汁会流出来）。
出餐：碗底先垫210g米饭→浇头连带汤汁一起盖在米饭上→撒香葱+白芝麻→碗下垫木托盘/竹垫→配勺子+韩式小菜（泡菜/萝卜）上桌。
装碗标准：浇头要盖住米饭的2/3，露出1/3白米饭——视觉上有层次感，客人先看到肉再看米饭。

出品流程

  1. 炒锅加色拉油30g（约两勺），烧至6成热
  2. 下肥牛130g炒至变色，加洋葱丝70g + 金针菇30g翻炒
  3. 加肥牛汁150g，大火烧开
  4. 加老抽2g上色 + 胡椒粉0.2g提鲜
  5. 大火收汁至汁浓稠挂在肥牛上（约1分30秒，不要收干）
  6. 盛入米饭210g上，撒香葱+白芝麻
🥩 肥牛汁配方（可批量 · 30份量）
原料用量备注
蒙古酱油4500g底味咸鲜
水4500g1:1兑酱油
白糖1000g提鲜平衡
蒜泥300g新鲜蒜泥
牛肉粉150g大喜大或同类
香油500g出锅前加·增香关键
黑胡椒粉30g
做法：除香油外所有料混合搅匀（不加热），分装冷藏。每份取150g，出餐前加香油5g搅匀再用。
🔑 关键标准：
• 炒肥牛用色拉油30g/份，不要用香油炒——香油加热会发苦
• 香油只在肥牛汁里加（5g/份），出锅前淋——生香不抢味
• 收汁标准：大火煮1分30秒左右，汁浓稠能挂住肥牛、锅底不留稀汤
• 如果觉得颜色太浅可多加1-2g老抽，不要加酱油——酱油多了会咸
⚠️ 防错防呆（5条）
① 肥牛不要炒太久——变色就加料，炒老了肥牛变硬嚼不动
② 收汁不要收太干——留一点汁拌饭才好吃，收到汁浓稠挂在肥牛上即可
③ 肥牛汁的咸度已调好——基本不用再加盐，新手最容易犯的错是额外加盐
④ 金针菇可以换成任何时令菌菇——白玉菇、蟹味菇都行
⑤ 出餐后建议配一小碟拌饭酱——客人自己调节辣度

🥚 变形体扩展 · 同一模式两种变形

共同标准：米饭210g（东北珍珠米4:糯米1 · 米水比1:1.1 · 浸泡30分钟 · 蒸饭柜最佳） · 碗装载具（韩式铜碗/日式丼碗） · 出餐垫白米饭2/3露1/3。以下变形体仅在浇头上做变化，其余标准与主推肥牛拌饭一致。
变形体一 · 老式拌饭（利润率最高）
出品规格：米饭210g + 炸鸡蛋3个 + 海苔碎5g + 白芝麻 · 配拌饭汁
做法：平底锅加色拉油约150°C（油没过鸡蛋）→ 打入3个鸡蛋 → 蛋清发白、蛋黄变色捞出 → 放在米饭上 → 撒海苔碎+白芝麻 → 配拌饭汁上桌（拌饭汁配方同KF_001石锅拌饭酱）
🔑 关键：鸡蛋用油炸不是煎——油量没过鸡蛋，炸出来的蛋白蓬松、蛋黄流心。不要用煎蛋——煎蛋蛋白紧实不蓬松。
💰 成本：~3.5元/份 · 建议售价18-25元 · 毛利率85%
适用场景：午餐简餐、学生市场、地摊。地摊版可卖15元，利润依然可观。——最简单的拌饭变形，只加鸡蛋不加肉。
变形体二 · 大酱拌饭（秋冬石锅款）
出品规格：五花肉40g + 拌饭菜130g + 金针菇25g + 小白菜20g · 配米饭210g
调味：大酱40g + 牛肉粉3g + 味精2g + 胡椒粉1g + 蒜末3g + 粗辣椒面2.5g + 细辣椒面3g
做法：炒锅加油 → 下五花肉炒香 → 加拌饭菜翻炒 → 加调料 → 加水没过菜 → 加大酱小火煮出酱味 → 加金针菇、小白菜大火收汁 → 加蒜末 → 盛入加热石锅出餐
🔑 关键：大酱拌饭用石锅出餐（不是碗），因为酱汁多需要保温。炒肉后先用辣椒面调色再加水——顺序错了颜色发灰。秋冬菜单替换肥牛拌饭，天热了换回来。
💰 成本：~5元/份 · 建议售价28-35元 · 毛利率82%
适用场景：冬季菜单、堂食场景。不适合外卖（石锅太重）。
⑦ 商业决策

💰 成本利润：肥牛拌饭~8元/份 · 售价28-35元 · 毛利率76-80%（主推）。变形体：老式拌饭~3.5元/份 · 售价18-25元 · 毛利率85%（利润王）；大酱拌饭~5元/份 · 售价28-35元 · 毛利率82%（秋冬替换款）。
三款怎么选：肥牛拌饭是主推（供应链优势最大），老式拌饭作为利润补充进入菜单，大酱拌饭在冬季替换肥牛拌饭。三款共用米饭标准，后厨增加一款变形的学习成本几乎为零。
⚠️ 注意：如果肥牛用烤肉边角料，成本可降到5-6元/份。

✅ 供应链优势：这是KF系列中供应链复用率最高的产品。烤肉店备了美肥就有肥牛拌饭——零新增备货。老式拌饭更简单——只要鸡蛋和海苔就行。

🎯 地摊版：肥牛拌饭⭐⭐⭐⭐ 老式拌饭⭐⭐⭐⭐⭐ 大酱拌饭⭐⭐。老式拌饭最适合地摊——米饭+炸鸡蛋+拌饭酱，3分钟一份，地摊卖15元，成本3.5元。
