矩阵定位：辣白菜炒饭在"基础型"右下端——传播力低但复购率高。它的角色不是拉新，是稳客单价+拉复购。搭配一碗汤（大酱汤/嫩豆腐汤）组成午间套餐，是提升客单价的利器。

⑥ 工艺配方 · 辣白菜炒饭（西塔标准版）
出品规格：米饭150g + 辣白菜100g + 煎蛋1个 + 海苔碎3g + 白芝麻
调味：白糖10g + 细辣椒面4g + 牛肉粉4g + 味精1.5g + 黑胡椒粉0.5g + 香油5g

🍚 米饭标准

用米：东北珍珠米（圆粒米，隔夜饭最佳）。辣白菜炒饭用隔夜饭（冰箱冷藏12小时以上）口感更好——隔夜饭水分少，炒出来粒粒分明。
没有隔夜饭怎么办：新蒸米饭盛出后摊开放凉至室温，冷藏30分钟再用。热饭直接炒会粘锅成一坨。
米水比：1:1.1（蒸饭柜），比拌饭少一点水——炒饭的米饭要偏干。
每份：150g熟饭（注意！辣白菜炒饭比拌饭少60g——因为辣白菜本身就是配菜，不需要太多米饭）。
保温：米饭提前分装好，炒饭前微波炉高火1分钟打热再炒——冷饭直接入锅升温慢。

🥬 辣白菜标准

推荐：延边辣白菜（宗家府或同类韩式辛奇），不要用国内超市的"辣白菜"——很多国产辣白菜是甜口的，炒出来没味道。
预处理：辣白菜取出后简单挤掉多余汤汁再切——汤汁太多的辣白菜下锅会"煮饭"而不是"炒饭"。挤出的辣白菜汤汁别扔，炒饭时加进去调味。
切法：粗切2-3cm见方，不要切太碎——太碎了吃不出辣白菜的口感。
辣白菜根部较硬：斜刀切薄，否则炒不软影响口感。
⚠️ 不同品牌的辣白菜咸度和酸度差异大：第一次做某个品牌时，少放盐炒完尝一下再补。
储存：开封后冷藏保存，7天内用完。变酸了可以做泡菜汤不能用炒饭。

出品流程

  1. 炒锅大火烧热，加色拉油20g（约一勺半），烧至7成热
  2. 下辣白菜100g，中火煸炒——炒到辣白菜边缘微焦、多余汤汁收干、白菜叶变透（约1分钟）
  3. 加白糖10g + 细辣椒面4g + 牛肉粉4g + 味精1.5g + 黑胡椒粉0.5g，翻炒均匀
  4. 加米饭150g，转中小火——用锅铲把米饭打散压开，不要用勺背压（会把米粒压碎）
  5. 炒至米饭粒粒分明、辣白菜均匀裹在每粒米上（约2分钟）
  6. 沿锅边淋香油5g（锅边高温瞬间激发出香气）
  7. 大火快炒5秒，出锅装碗
  8. 码上煎蛋（单面煎·蛋黄流心→蛋白全熟）→撒海苔碎+白芝麻→出品
⚠️ 防错防呆（6条）
① 辣白菜一定要先炒干汤汁再下米饭——汤汁多的辣白菜炒出来的是"辣白菜泡饭"不是炒饭
② 米饭一定要用打散了的冷饭——整块冷饭下锅炒不匀，急用时用手抓散
③ 调味顺序很重要：先炒干辣白菜→调味→再下饭。顺序错了=辣白菜没味，菜是菜饭是饭
④ 香油必须出锅前淋——不要炒的时候放香油，会挥发。沿锅边淋，高温瞬间激香
⑤ 煎蛋要单面煎：蛋黄流心、蛋白全熟。双面煎蛋黄凝固了=丧失了拌饭吃时的口感变化
⑥ 不要加酱油（生抽/老抽）——辣白菜本身有咸味和颜色，加酱油会灰暗且过咸

🥓 变形体扩展 · 同一模式两种变形

共同标准：米饭150g（隔夜饭·粒粒分明） · 辣白菜100g（挤汁后切） · 煎蛋1个 + 海苔碎。以下变形体仅在浇头食材上做变化，炒饭底不变。
变形体一 · 五花肉辣白菜炒饭（溢价款）
出品规格：米饭150g + 辣白菜100g + 五花肉薄片40g + 煎蛋1个 + 海苔碎
做法：先下五花肉片煸炒出油（五花肉不用另加油）→ 炒至微焦卷曲 → 下辣白菜继续炒 → 调味 → 下米饭炒散 → 淋香油出锅
🔑 关键：五花肉自带油，炒饭更香，而且肉香和辣白菜的酸辣形成经典搭配。五花肉切薄片（3mm），太厚了炒不熟出油不够。
💰 成本：~4.5元/份 · 建议售价22-28元 · 毛利率83%
适用场景：堂食+外卖通用。适合已有五花肉备货的烤肉店，零新增备货。
变形体二 · 芝士辣白菜炒饭（年轻客群款）
出品规格：米饭150g + 辣白菜100g + 马苏里拉芝士40g + 煎蛋1个
做法：辣白菜炒饭按标准流程炒好 → 盛入可进烤箱的碗中 → 铺上芝士碎 → 烤箱180°C烤5分钟至芝士融化微焦 → 放煎蛋 → 撒海苔碎出品。也可用喷枪直接烤化芝士（更快）。
🔑 关键：芝士铺满碗面不露米饭，烤出来才有"瀑布芝士"效果。用马苏里拉（拉丝效果好），不要用切达（容易焦）。
💰 成本：~5.5元/份 · 建议售价25-32元 · 毛利率80%
适用场景：堂食拍照引流款，适合年轻客群和网红店。外卖不适合（芝士凉了就不拉丝了）。
⑦ 商业决策

💰 成本利润：辣白菜炒饭~3元/份 · 售价18-25元 · 毛利率87-90%（KF系列利润王）。
变形体：五花肉炒饭~4.5元/份 · 售价22-28元 · 毛利率83%；芝士炒饭~5.5元/份 · 售价25-32元 · 毛利率80%。
三款怎么选：基础版走量+地摊核心（成本最低），五花肉版走堂食客单价提升，芝士版走年轻客群+社交媒体。
⚠️ 注意：因为利润太高很容易让人想"多加肉"——不要这么做。辣白菜炒饭的核心竞争力就是"便宜好吃"。一加肉就会变成辣白菜炒肉不是辣白菜炒饭，顾客会觉得贵。

✅ 供应链优势：辣白菜批量采购可做到8-12元/kg（宗家府10kg商用装~100元），单份成本不到1元。米饭自己蒸，鸡蛋批量采购~0.6元/个。三样食材全国任何一个菜市场都能买到。
🎯 地摊版：⭐⭐⭐⭐⭐ 极致适合地摊。出餐2分钟，成本~3元，地摊卖12-15元，客人觉得便宜又好吃。搭配一杯饮品或一碗汤变套餐，单份利润8-10元。
