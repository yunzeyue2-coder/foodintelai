⑥ 工艺配方
🔥 主推 · 拌肉型三大变形体（VC_K021）
① 秘制大块肉
鲜肉上脑10斤、切1cm厚片 → 小苏打嫩化30分钟 → 洗两遍 → 秘制大块肉酱抓拌。200-250g/份。
秘制大块肉酱（10斤肉）： 盐25g + 牛肉粉10g + 味精10g + 白糖70g + 黑胡椒粉3g + 二锅头5g + 肉宝王1g + 牛肉酱30g + 苹果+洋葱+姜+蒜打汁

② 特色拌肉
肋扇肉/上脑200g → 拌肉料18g/斤 + 香菜 + 圆葱丝 + 豆油。38-48元。
拌肉料（批量）： 盐180g + 细味精160g + 白糖160g + 孜然粉半碎50g + 千里香籽粉24g + 小茴香碎60g + 芝麻30g + 辣椒面50g + 麻辣鲜10g + 十三香10g

③ 黑椒牛肉粒
长肋条斜切方块24块/170g → 黑胡椒酱15g/份 + 干冰起雾。48-58元。
🧂 烤肉撒料与蘸料
韩式烤肉干料（通用配方·批量250份）
十三香1包 + 麻辣鲜1包（46g） + 孜然粉500g（半碎） + 黄豆粉500g（炒熟打粉） + 细辣椒面500g（二荆条） + 芝麻粉250g（半碎）
全部混合，密封30天。每份5-8g，小碟蘸食或烤后撒。

麻酱蘸料（经典韩式·单份）
芝麻酱20g + 香油5g + 盐1g + 韭菜花2g + 腐乳汁2g + 白糖1g
油澥法（不用水澥）。

海鲜汁（批量150份）
酿造酱油2500g + 白砂糖2500g + 清酒800g + 味精150g → 搅匀冷藏
每份30g小碟，蘸食原味烤肉。

⑧ 未来趋势
趋势一 · 酱料升级：大块肉酱可延伸出辣白菜酱、柚子酱等韩式变体，打造「一肉多吃」体验。

趋势二 · 部位细分：精品部位赛道持续升温（胸口、三筋、护心肉），建议增加牛小肠、牛肚领等韩式经典内脏品类，形成「部位专营」差异化。

趋势三 · 拼盘场景化：摩天轮/9宫格可绑定节日限定（情人节·中秋·圣诞），搭配定制摆盘器具，提升客单价与传播属性。

趋势四 · 小份化/一人食：针对午市/一人食场景，推出小份拌肉（100g/22-28元）和 mini 拼盘，拓宽消费频次。

趋势五 · 数字化配方管理：所有酱料/拌料配方建立标准化 SOP，支撑多店复制与品质统一。
