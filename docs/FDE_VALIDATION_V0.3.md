## 2. 系统链路

```
用户画像输入（城市/预算/经验/品类）
       ↓
Decision Scenario（粉面创业/早餐创业/社区店...）
       ↓
Decision Rules（条件匹配 → 资产推荐）
       ↓
FDE Score Model（品类评价：市场/供应链/运营/竞争/匹配 = 100分）
       ↓
Match Model（用户匹配：资金/经验/城市/运营/意愿 = 100分）
       ↓
Decision Logic（优势/风险/建议 → 解释层）
       ↓
Relations Index（Framework → Case → Research → 证据链）
       ↓
Asset Evidence（框架/案例/研究 → 引用展示）
       ↓
Decision Result（推荐 + 评分 + 等级）
```

## 3. 验证案例（回归测试基线）

### Case A：郑州·20万·首次创业·粉面

**画像**

| 维度 | 值 |
|------|-----|
| 城市 | 郑州（二线） |
| 预算 | 20万 |
| 经验 | 首次创业 |
| 方向 | 粉面 |

**匹配规则**：RULE-FM-001（粉面创业-标准路径）

**输出**

| 指标 | 值 |
|------|-----|
| 推荐方向 | 粉面模型（米线/热干面/牛肉面） |
| FDE Score | 79/100 |
| Match Score | 76/100 |
| 综合评分 | 78/100 |
| 等级 | 比较适合 |
| 可信度 | 85% |
| 引用资产 | FW-008, RS-mixian_7worlds, RS-mixian_yunnan |

**风险**
- 供应链区域化
- 区域口味差异
- 竞争密度逐年上升

**分析要点**：系统识别了资金规模匹配、新手友好品类、二线城市适配。

## 4. 验证指标

### ① 推荐差异性 ✅

不同用户→不同答案。三组测试输出了完全不同的规则、资产、风险。

### ② 评分合理性 ✅

分数随条件变化：Match Score 在 74~81 之间波动，用户B经验丰富→得分最高。

### ③ 资产相关性 ✅

relations-index 支撑引用解释，Framework/Research/Case 可溯源。

### ④ 风险独立性 ✅

不同品类输出了不同风险：粉面→区域口味，炸鸡→租金，卤味→人工。

### ⑤ 可解释性 ✅

decisionLogic 提供了5维评分理由，每条推荐有 relationType + reasonDetail。

## 5. 当前已知问题

1. **跨品类关联复核**：RULE-BF-001 引用早餐研究输出给卤味场景，需确认逻辑是否成立
2. **规则数量有限**：当前仅6条规则，覆盖场景不够广
3. **Match Model 需校准**：维度权重基于经验设定，缺少真实用户反馈校准
4. **FDE Score 模拟简化**：测试中维度评分使用模拟算法，需接入真实决策逻辑
5. **证据完整度展示**：目前页面支持 evidenceCoverage 字段，但数据层未完全打通
6. **案例资产引用**：relations-index 中案例关联偏弱，缺少独立案例索引
