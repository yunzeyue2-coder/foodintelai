# FDR Evidence Boundary Specification

## 一、第一原则

> **任何关键指标，在缺乏可验证数据时，不得通过经验、模型或语言生成补齐为事实数字。**

```
有数据     → Quantify（量化）
有专家知识 → Qualify（标注行业判断）
有理论     → Framework（给框架）
数据不足   → Unknown（写无法判断）
必须实测   → Validation Required（设计实验）
```

## 二、Evidence Status 五级 Schema（必须进入数据模型）

### A · Evidence-backed（数据证据）

```json
{
  "evidence_status": "A",
  "evidence_type": "data",
  "source": "zz_fried_label_table_v03.csv",
  "coverage": 0.678,
  "denominator": 2397,
  "formula": "HHI = sum((share_i*100)^2)",
  "filter": "工艺=生炸/现炸 AND 风格!=Unknown",
  "version": "ONT-PIPELINE-V0.3",
  "confidence": "high"
}
```

**决策权限：可直接进入 Decision。**

### B · Expert-backed（专家判断）

```json
{
  "evidence_status": "B",
  "evidence_type": "expert_judgment",
  "expert_basis": "沧林食品工业20年：生炸工艺对操作者技能依赖高",
  "data_supported": false
}
```

**决策权限：可进入 Conditional Decision。必须与数据证据视觉分离。**

### C · Framework-only（框架）

```json
{
  "evidence_status": "C",
  "evidence_type": "framework",
  "requires_validation": true,
  "framework": "Unit Economics: Revenue=Orders×AOV; Break-even=Fixed Cost/Contribution per Order"
}
```

**决策权限：不得直接形成 Go。只能给变量/框架/验证方法。**

### D · Unknown（数据缺失）

```json
{
  "evidence_status": "D",
  "reason": "insufficient_observable_data",
  "unknown_rate": 0.495
}
```

**决策权限：不得形成确定性判断。明确写"无法判断"。**

### E · Validation-required（必须实测）

```json
{
  "evidence_status": "E",
  "validation_protocol": "30天工艺良率测试：连续10天记录，目标≥90%稳定出品",
  "gate": "良率<90% → Skill Gate FAIL → 不能进入"
}
```

**决策权限：必须通过实验 Gate 后才能升级。**

## 三、Evidence → Confidence → Decision Authority

| 证据等级 | 证据类型 | 决策权限 |
|---------|---------|---------|
| A | data | 可直接进入 Decision |
| B | expert_judgment | 可进入 Conditional Decision |
| C | framework | 不得直接形成 Go |
| D | unknown | 不得形成确定性判断 |
| E | validation_required | 必须通过实验 Gate 后才能升级 |

## 四、反例（禁止）与正例（必须）

**错误方式 ❌**
> "日均100单 / 客单25元 / 毛利率62% / 月利润3.8万元" —— 全是编的

**正确方式 ✅**
> "当前缺乏单店经营数据，因此无法判断该品类在郑州的真实盈亏平衡点。"
> + Unit Economics Framework
> + "关键参数待30天经营实验校准"

## 五、Scenario 规范（M12 特别约束）

> **Scenario ≠ 编三个数字。** 没有真实经营数据时，禁止：

❌ Bull：日均150单 / Base：日均100单 / Bear：日均50单 —— 伪精确

**允许：**
```
Scenario Framework:
Demand × AOV × Contribution Margin × Fixed Cost

识别决策对变量的敏感性：
  订单量 ≥ X 且 贡献利润 ≥ Y → GO
  订单量 ≥ X 但 复购不足     → MODIFY
  连续 N 天低于 Gate         → STOP
```

Scenario 的核心不是预测未来，而是**识别决策对变量的敏感性**。

## 六、产品差异化定位

- 普通咨询报告：没有数据 → 猜一个
- 普通 AI：没有数据 → 生成一个看起来合理的数字
- **FoodIntelAI：没有数据 → 明确告诉你不知道，并设计实验把"不知道"变成"知道"**
