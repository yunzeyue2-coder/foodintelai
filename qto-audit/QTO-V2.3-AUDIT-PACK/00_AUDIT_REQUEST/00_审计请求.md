## 一、六项审计

### 1. Evidence Authority Gate
- A/B/C/D/E 分级是否符合 Decision Authority 原则？
- C 是否真的只能进入 conditions？代码里是否有路径让 C 混入主理由？
- **D/E 是否在所有入口都被阻断**，还是只在 decision_memo 的 Reason 直连被阻断？

### 2. Sample Coverage Gate
- 六变量（coverage/bias/geographic/penetration/completeness/temporal）定义与权重是否合理？
- GLOBAL/REGIONAL/LOCAL/INSUFFICIENT 四级 + HARD_FLOORS 硬底线是否存在逻辑漏洞？
- 已知修复：加权可被"单维度极差其他满分"绕过（coverage=0.01→曾GLOBAL），已加硬底线拦截。
- **请继续攻击**：硬底线是否有绕过路径？如 coverage 分母虚报、bias 自评虚高、geographic 分类模糊——Gate 能否识别参数本身的可信度？

### 3. 两 Gate 组合逻辑（正交否决）
```
Evidence Authority × Sample Coverage → Decision Qualification
```
- 是否可能：Authority 全 PASS 但 Coverage 极差 → 仍输出决策？（应：任一否决 → 整体降级）
- 是否可能：Coverage 全 PASS 但 Authority 有 D/E → 仍输出决策？
- **两个 Gate 的否决权是否正交？还是其中一个高分可抵消另一个的否决？**

### 4. Regression 三案例
- 炸鸡 GLOBAL / 米线 LOCAL / 极端案例 INSUFFICIENT——是否稳定可复现？
- 结果对参数变化是否过于敏感？

### 5. 反向审计
- 遮掉最终 Decision，只看 Evidence + Gate 输出，能否重推同样的 Scope 和 Qualification？

### 6. 绕过 Gate 的隐藏路径（最高优先——图级审计）
> **不要在字段级找 D/E，要在 Decision Graph 上找所有 D/E Evidence → Final Decision 的间接路径。**

```
D → Insight → Hypothesis → FDE Score → Decision
D → Insight → Decision（间接引用）
D → Hypothesis → Decision
D → Condition → Decision（藏在条件里影响判断）
D → Narrative（Executive Summary/Recommendation 文本引用）
D → FDE 评分维度 → Decision
```

**必须证明：D ──X──→ Decision（所有路径）。** 否则 Authority Gate 只是字段校验器，还不是 Decision Authority。

## 二、审计重点（图级）

### ① Evidence Lineage（证据谱系）
每个 Decision 必须可追溯：`Decision → Reason/Score/Condition → Insight/Hypothesis → Evidence`，然后检查**最低 Evidence Authority**（链上任一环节是 D/E → 整条链权限不高于 D）。

### ② Authority Propagation（权限传播）⭐ 当前最缺
Authority 必须沿 Evidence Graph **向上继承**：
```
E008(D) → I005 → I005 的 Authority 不能高于 D
I005(D) → H003 → H003 也不能获得 A/B 权限
H003(D) → FDE Score → 该 Score 不得作为独立 Decision Authority
```
**问题：当前代码是否实现了这个传播？还是只有 Reason 直连被检查？**

### ③ Negative Evidence（负证据）
D 级证据可作为 Challenge/Condition/Unknown（低权限≠没用），但**不能**升级成事实判断。如"D级资料提示可能存在盈利模型问题"≠"盈利模型已被证明存在问题"。
**检查：Evidence Authority ≠ Evidence Utility 是否成立？**
