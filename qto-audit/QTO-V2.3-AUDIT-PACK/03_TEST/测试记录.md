# QTO-V2.3 测试记录（Regression + P0修复攻击测试）

## 一、P0 漏洞发现与修复（2026-08-10 内部预审）

### 漏洞
Sample Coverage Gate 加权平均可被"单维度极差但其他维度满分"绕过：

```
coverage=0.01（采样1%）但 bias/geographic/penetration/completeness/temporal 全满分
→ 加权分 0.752 → 曾误判 GLOBAL（采样1%却能输出全城结论！）
geographic=0.05（单点）同理 → GLOBAL
temporal=0（单日快照）→ GLOBAL
```

### 根因
纯加权平均 = 可被补偿的评分模型。关键维度无否决权。

### 修复
增加单维度硬底线（HARD_FLOORS）：
```
coverage < 0.30     → 最高 LOCAL（采样严重不足，仅样本区初步信号）
geographic < 0.25   → 最高 REGIONAL（地理覆盖不足）
bias < 0.40         → 最高 REGIONAL（选择偏差严重）
```
任一关键维度跌破底线即降级，**不被加权稀释**。

### 修复后验证（攻击测试 5/5 通过）
```
攻击1: coverage=0.01 其他满分 → LOCAL   ✅（原 GLOBAL）
攻击2: geographic=0.05 其他满分 → REGIONAL ✅（原 GLOBAL）
炸鸡(全城2397家)        → GLOBAL   ✅
米线(金水区200家)       → LOCAL    ✅（coverage 硬底线触发）
极端(10000家采样50家)   → INSUFFICIENT ✅
```
