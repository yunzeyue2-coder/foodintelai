FoodIntelAI Framework Layer / 米线研究周·资产沉淀

## 〇、通用原则(写入 FIF Framework 通用规范)

> **不要让"评分体系"制造虚假的确定性,而要让"证据体系"决定输出精度。**

不是:七个维度 → 每个打 0-100 分 → 加总出一个综合分。

而是:证据等级 → 决定这个维度能不能量化、量化到什么精度 → 决定这个变量能不能被下游模型直接调用。

每个维度固定输出以下字段:

```
Dimension        维度名称
Assessment       判断结果(定性)
Score Precision  评分精度(区间 / 暂不量化,证据等级A才允许出单一数字)
Evidence Level   证据等级(A-E)
Evidence         依据(真实来源,不可编造)
Validation Status 验证状态
待补/待验证        下一步需要什么数据才能升级证据等级
Model Availability 模型可用状态
```

**证据等级 → 数字精度 对照表**

| 证据等级 | 定义 | 允许的表达精度 |
|---|---|---|
| A | 公开数据/可数数据直接支撑(门店数、市场规模等硬数字) | 可给单一分数,需注明计算依据 |
| B | 多来源研究交叉验证,但本质是定性归纳 | 只给区间(如 70-85) |
| C | 专家判断/研究团队归纳,无法交叉验证 | 只给方向性判断 + 窄区间,标注"研究判断" |
| D | 案例推断(从个别案例外推到品类整体) | 不出分数,只给判断方向,标注"待数据增强" |
| E | 假设(尚无证据,仅为待验证命题) | 不出分数,只列为待验证问题 |

**Model Availability(模型可用状态)**

| 状态 | 含义 | 下游调用方式 |
|---|---|---|
| Ready | 可进入计算 | FDE 可直接作为决策变量 |
| Partial | 辅助判断 | 可参与判断,不单独作为决策依据 |
| Reference | 仅作为背景 | 只能在解释文本中引用,不进模型 |
| Need Data | 暂不可调用 | 标记为待补数据项 |

## 一、七维判断框架

### ① 产业基础层 Industrial Base
判断这个品类有没有产业土壤:原料产区依赖度 / 供应链成熟度 / 工业化程度

### ② 地域生态层 Regional Ecology
判断为什么诞生在这里:地理环境 / 农产品基础 / 饮食文化 / 人口迁移

### ③ 产品形态层 Product Architecture
判断是不是容易形成统一认知:产品边界清晰度 / 品类命名统一度 / 消费认知成本

### ④ 技术工艺层 Process Barrier
判断复制难度:技术依赖 / 师傅依赖 / 设备依赖 / 时间窗口

### ⑤ 风味资产层 Flavor Asset
风味识别度 / 文化绑定度 / 外地接受成本 / 替代可能性
(对应 Day6 已建立的"味觉半径"细分变量:气候习惯/调味阈值/消费频率/价格敏感度)

### ⑥ 交付系统层 Delivery System
最佳赏味时间 / 堂食依赖 / 外卖适配 / 标准化损耗

### ⑦ 全国化层 Scaling Potential
供应链迁移能力 / 品牌表达能力 / 门店复制能力 / 价格带空间
(对应 Day6 已建立的"全国化三重约束模型":物理半径/味觉半径/认知半径)

## 二、三个插件设计(架构说明,不含具体打分)

### 插件1:区域食品生态分析器
**输入**:任意地方品类(如"河南烩面")
**输出**:产业优势 / 最大限制 / 迁移风险,均按证据等级标注,不强行给综合分
**依赖**:FIF-37 一、二维(产业基础层 + 地域生态层)

### 插件2:风味迁移风险分析器
**输入**:品类的风味结构描述
**输出**:Flavor Transfer Index(方向性风险判断,不是精确指数值),由四个子变量构成:
- 地方依赖度
- 味觉冲击强度
- 文化理解成本
- 替代难度

**说明**:这四个子变量目前普遍只能到证据等级 C(专家/研究判断),在有跨区域消费数据(如外地门店复购率、退货/差评关键词)之前,不允许把 Flavor Transfer Index 升级为 Ready 状态的精确数字。

### 插件3:全国化路径判断器
**输入**:品类的供应链/品牌/消费认知现状
**输出**:该品类应走哪类路径——供应链型 / 品牌型 / 加盟型 / 工业化型(定性判断,附带每条路径成立的前提条件),不输出"综合评分"

## 三、米线 DNA 示例 V0.1 —— 模型验证记录

> 声明:以下不是"米线的标准答案",是 FIF-37 框架用米线六天研究数据做的**第一次验证记录**。用于检验框架本身是否可用,不作为对外发布的结论性资产。

### ① 产业基础层
- **判断**:强
- **评分精度**:暂不量化(尚无全国米粉加工产能/供应链规模数据)
- **证据等级**:B
- **依据**:全国米粉门店34万家,市场规模775亿元、同比+8.4%(红餐大数据,2025.3 / 2024数据);云南、广西已形成原料-加工-区域供应链的产业带
- **验证状态**:部分验证
- **待补**:全国米粉加工企业数量、产能规模数据
- **Model Availability**:Partial

### ② 地域生态层
- **判断**:强
- **评分精度**:暂不量化
- **证据等级**:B
- **依据**:七大区域体系已在 Day1-5 完成对比(区域分化明显,风味/工艺/客单价均有实质差异)
- **验证状态**:已形成研究判断
- **待补**:区域间消费者认知调研数据(目前是研究团队归纳,非一手消费者数据)
- **Model Availability**:Partial

### ③ 产品形态层
- **判断**:中等偏弱(存在明显分裂)
- **评分精度**:暂不量化
- **证据等级**:C
- **依据**:米线/米粉/卷粉/河粉命名边界模糊,区域间对同一品类的认知不统一(Day6 已指出蒙自源门店数存在1700家/1474家的口径冲突,侧面反映统计与命名标准均不统一)
- **验证状态**:研究判断
- **待补**:全国性消费者认知调研(品类命名混淆程度的量化数据)
- **Model Availability**:Reference

### ④ 技术工艺层
- **判断**:存在挑战
- **评分精度**:暂不量化
- **证据等级**:D
- **依据**:云南本地"重汤、重鲜、慢消费"的工艺特征,与工业化复制之间存在张力,但目前无工业化损耗率、设备标准化率等硬数据支撑
- **验证状态**:待数据增强
- **待补**:预包装/工业化米线企业的设备、损耗、良品率数据
- **Model Availability**:Need Data

### ⑤ 风味资产层
- **判断**:中等偏弱
- **评分精度**:暂不量化
- **证据等级**:C
- **依据**:Day6 已定义味觉半径四变量(气候习惯/调味阈值/消费频率/价格敏感度);云南消费场景(早餐/重汤/慢消费)与全国主流场景(午餐/快节奏/高翻台)存在系统性差异
- **验证状态**:专家判断
- **待补**:跨区域门店复购率、外地消费者评价关键词等一手数据
- **Model Availability**:Reference

### ⑥ 交付系统层
- **判断**:堂食依赖度较高,外卖适配有限
- **评分精度**:暂不量化
- **证据等级**:C
- **依据**:云南米线消费场景强调现煮、热汤,与Day6"消费时段窗口"维度的既有判断一致
- **验证状态**:研究判断
- **待补**:主流米线品牌外卖订单占比、口感损耗投诉率
- **Model Availability**:Reference

### ⑦ 全国化层
- **判断**:中等——四种迁移机制(供应链先行/品类重构/场景迁移/文化资产)均已尝试,但没有一种跑通全流程
- **评分精度**:暂不量化
- **证据等级**:B(基于蒙自源超1700家/1474家、阿香670家等真实门店数据,以及螺蛳粉/沙县/兰州牛肉面三个跨品类对照案例)
- **依据**:Day6"全国化三重约束模型"(物理半径/味觉半径/认知半径)已验证——头部米线品牌规模仍停在千店级,距离"全国性品类资产"量级仍有差距
- **验证状态**:已验证(机制层面);消费认知变化速度尚难预判
- **待补**:资本市场对米线赛道的实际投资数据(单轮融资规模)
- **Model Availability**:Partial

### 综合诊断卡(不出综合分)

```
品类:中国米线

综合判断:
区域资产强,产业基础较强,全国化能力中等

最大限制:
产品形态分裂(证据等级C) × 风味迁移成本(证据等级C)

主要机会:
供应链标准化 + 产品命名/认知统一

当前可被下游模型直接调用的变量(Model Availability = Partial 及以上):
产业基础、地域生态、全国化潜力

暂不可调用(Need Data):
技术工艺层
```

## 四、下一步升级路径

证据等级不是固定的,接入以下数据源后可逐级收紧:
- 美团/窄门餐眼门店数据 → 产品形态层、交付系统层 可能从 C 升到 B
- 高德 POI 数据 → 地域生态层 可能从 B 升到 A
- 企业/供应链数据 → 技术工艺层 可能从 D 升到 C
- 跨区域消费者调研 → 风味资产层 可能从 C 升到 B

升级规则:任何等级跃迁,必须附带新增数据来源说明,不能凭"感觉更有把握了"直接调高等级。
