FIP研究原则6 条
FIP 研究原则 FoodIntelAI Principles FIP
定义：食品产业研究五项基本原则的编码体系
包含系统原则、因果原则、消费者优先原则、证据原则、边界原则。构成所有产业研究的底层逻辑——不依赖直觉和经验，而是系统框架、消费者起点、证据说话、知边界。
FIP-001 系统原则 System Principle FIP
定义：产业是八链因果系统，不可孤立研究
消费者→需求→场景→渠道→产品→技术→供应链→产业格局八链传导。任何单一环节变化会通过因果链传导至其他环节。研究不能停留在局部，必须放在系统里理解。
FIP-002 因果原则 Causality Principle FIP
定义：穿透现象寻找因果，而非描述表象
建立现象→原因→规律→模型的完整分析路径。结论需穿透「是什么」到「为什么发生、为什么成功、为什么失败」，避免停留在表面描述。
FIP-003 消费者优先原则 Consumer First Principle FIP
定义：需求变化是产业变化的起点和归因
技术、供应链、渠道变化都是现象而非原因。消费者需求变化才是真正起点。研究消费者→需求变化→产业响应，而非从供给侧倒推。研究从消费者出发。
FIP-004 证据原则 Evidence Principle FIP
定义：三级信息分级使用，C级不可作核心结论
区分事实（已发生可验证）、判断（基于事实的分析）、假设（需验证的推演）。每级信息有不同引用权限。无可靠来源的判断需标注来源等级。
FIP-005 边界原则 Boundary Principle FIP
定义：每个框架有适用范围和边界条件
任何分析模型不能超出已验证的品类和场景。跨品类应用需重新验证框架适配性。不承认「普适规律」，只承认「在特定条件下成立的规律」。
FIF分析框架6 条
FIF 分析框架 FoodIntelAI Frameworks FIF
定义：五个产业分析标准框架的编码集合
包括七维决策框架、全国化分析、品类定位、商业模式分析、价值链分析。每个框架回答一个特定分析问题——该不该进入、能否全国化、在什么位置竞争、靠什么赚钱、利润在哪产生。
FIF-001 七维产业决策框架 Seven-Dimension Decision Framework FIF
定义：七个递进问题判断食品产业值不值得进入
产业基础·市场定位·商业模式·产业周期·竞争优势·组织能力·资本价值。前一个问题的答案决定后一个问题能不能问。一维不成立，后续维度无意义。已验证于卤味、炸鸡。
FIF-002 全国化分析框架 National Expansion Framework FIF
定义：五变量判断品类能否全国化
供应链成熟度×标准化深度×消费认知统一性×场景一致性×组织复制能力。供应链成熟≠全国品牌——五个变量缺一不可。已验证于卤味全国化分析。
FIF-003 品类定位框架 Category Positioning Framework FIF
定义：产品×渠道×场景×供应链四维定位
一个品类不在所有维度竞争，在特定位置竞争。四维坐标定位品类的核心竞争空间。目前处于优化中。
FIF-004 商业模式分析框架 Business Model Framework FIF
定义：五种经营模型的识别与天花板判断
手艺驱动型/流程驱动型/供应链驱动型/品牌驱动型/平台驱动型——各有各的天花板和杠杆。已验证于早餐产业（价格带锁死商业模式）。
FIF-005 价值链分析框架 Value Chain Framework FIF
定义：从原料到消费者，利润在哪产生和消耗
不是品牌竞争，是价值链竞争。利润在特定环节产生、在特定环节消耗。找准价值链核心节点是品类突破的关键。目前处于定型中。
FIS系统模型6 条
FIS 系统模型 FoodIntelAI Systems FIS
定义：五个产业系统模型的编码集合，揭示运行机制
包括八链因果模型、五世界分类模型、品类生命周期模型、老板自由度模型、压力测试与脆弱性分析。每个模型揭示产业运行的一个特定剖面，不追求完整映射。
FIS-001 食品产业系统模型（八链因果模型） Eight-Chain Causal Model FIS
定义：八链因果传导解释产业变化的底层机制
消费者→需求→场景→渠道→产品→技术→供应链→产业格局。方向不可逆。正向分析可追溯变化源头，反向预测可推演影响路径。基础模型，所有分析的起点。
FIS-002 五世界分类模型 Five Worlds Classification FIS
定义：卤味品类内部分为五个竞争逻辑不同的世界
休闲·佐餐·地方·餐饮·工业——以卤味产业为原型建立的品类内部分类体系。同一品类内部不同世界的竞争逻辑完全不同，可迁移至其他复杂品类。已验证。
FIS-003 品类生命周期模型 Category Lifecycle Model FIS
定义：品类发展的五阶段演变模型
导入→成长→成熟→分化→重构。每个阶段的关键变量、竞争焦点、利润结构不同。判断品类所处阶段，选择对应策略。已验证于卤味、炸鸡。
FIS-004 老板自由度模型 Owner Freedom Model FIS
定义：三指标判断门店能否脱离老板独立运转
生产自由度·管理自由度·复制自由度。三个指标判断一家店能否脱离老板独立运转。早餐产业验证，可迁移至所有小餐饮。老板自由度越高，连锁化潜力越大。
FIS-005 压力测试与脆弱性分析 Stress Test & Vulnerability Analysis FIS
定义：研究外部冲击和内部缺陷下的产业脆弱点
外部冲击（原料波动/消费变化/政策）×内部缺陷（供应链依赖/人员依赖）×极端情景（成本上涨30%/渠道失效）。不只研究为什么成功，也研究为什么可能失败。定型中。
FIM研究方法6 条
FIM 研究方法 FoodIntelAI Methods FIM
定义：五个标准研究方法的编码集合
覆盖从「如何研究」到「如何写作」的完整生产链：八步研究法、第一性原理分析、多模型并列分析法、数据交叉验证法、认知重构写作法。FIP原则的执行层。
FIM-001 八步研究法 Eight-Step Research Method FIM
定义：八步标准化研究生产流程
锁定框架→宏观资料→聚焦单篇→审结构→中微观资料→检查对比→写作→审核→配图→发布。先研究后动笔，数据缺口表先行。默认流程，适合大多数品类分析。
FIM-002 第一性原理分析 First Principle Analysis FIM
定义：从产业基本物理和经济约束推导结论
回归产业最基本的物理约束和经济学规律。不依赖既有经验框架，从零开始推导品类的结构性天花板。适合创新型品类或需打破既有认知框架的场景。
FIM-003 多模型并列分析法 Multi-Model Parallel Analysis FIM
定义：不能用单一模型解释复杂品类
任何食品品类不能用单一模型解释。按品类/区域/规模分别建立模型，并列分析，不下统一结论。不绝对化。默认方法，适用于所有分析。
FIM-004 数据交叉验证法 Cross-Validation Method FIM
定义：重要数据需至少两个独立来源验证
企业规模不能只看自述，需结合财务、渠道、供应链、原料消耗交叉印证。无法验证的数据标记为待验证信息。防止单一来源数据误导。默认方法。
FIM-005 认知重构写作法 Cognitive Restructuring Writing FIM
定义：重建读者认知坐标系的写作范式
不是「观点→数据→结论」，而是反常识事实→拆解表象→揭示底层矛盾→提出新框架→留下开放问题。适用于面向公众的深度文章。
FIE证据体系5 条
FIE 证据体系 FoodIntelAI Evidence FIE
定义：四级证据分级体系，界定信息的可信度和引用方式
A级（高可信事实）→B级（可信参考信息）→C级（待验证信息）→D级（行业经验判断）。FIP-004证据原则的执行层。让一篇文章的信息可信度在一分钟内可判断。
FIE-A 高可信事实 High-Credibility Facts FIE
定义：官方公开数据、上市公司公告、权威机构报告
可验证经营数据。可作为核心结论依据。注意：A级不等于100%准确——需关注采集时间和口径差异。
FIE-B 可信参考信息 Credible Reference FIE
定义：企业公开信息、行业访谈、专业媒体报道
可作为辅助论据，需标注来源。在证据等级中介于绝对可信与待验证之间。
FIE-C 待验证信息 Unverified Information FIE
定义：企业宣传数据、市场传言、单一来源观点
不得直接作为核心结论依据，需标注「待验证」。可用于提出假设方向，但不能作为分析基础。
FIE-D 行业经验判断 Industry Experience Judgment FIE
定义：基于从业经验的定性判断，无公开数据支撑
用于方向性分析，不用于精确论证。需注明「行业经验」。虽有价值但不能作为核心结论依据。关键是标注来源等级，而非排除。
FDE决策引擎2 条
FDE 食品产业决策引擎 Food Decision Engine FDE
定义：从问题识别到商业决策的七层诊断体系
三个原则：先定位再解决、所有结论可验证、所有方案可复现。诊断是过程，决策才是产品。跨品类可复用——不同品类模型不同，诊断逻辑相同。
七层诊断体系 Seven-Layer Diagnostic System FDE
定义：FDE的七层递进诊断流程
问题分类→产业模型→诊断树→验证体系→解决方案库→标准数据库→决策建议。每一层的输出是下一层的输入。从自然语言问题到商业决策的可回溯推理链路。
CAT品类模型4 条
炸鸡六维控制模型 Six-Dimension Fried Chicken Control Model 品类
定义：炸鸡品类的六维产业控制体系
原料·腌制·裹粉·油炸·设备·供应链——六个可独立排查的控制维度。每维都是可控变量，通过调节六维参数实现产品稳定和品质控制。已发布完整白皮书（8篇·约6.5万字）。
卤味七维产业决策模型 Seven-Dimension Braised Decision Model 品类
定义：卤味品类的七维产业分析标准
基于FIF-001七维决策框架应用于卤味品类的完整白皮书。首次应用FIS-002五世界分类模型。约18万字完整研究体系，经卤味行业深度验证。
早餐五维模型 Breakfast Five-Dimension Model 品类
定义：早餐品类的五维分析模型
用于早餐产业的系统分析和决策判断。验证了老板自由度模型、商业模式分析框架等FIS/FIF子框架在早餐品类的适用性。涵盖早餐九大门派分析。
面食产业模型 Noodle Industry Model 品类
定义：面食品类的七篇系统研究系列
包含手工vs机器、三张底牌、陕西的面、西安泡馍、凉皮三姐妹等7篇完整研究。验证FIM研究方法在面食品类的适用性。W26完成全部7篇。
GEN通用概念8 条
八链因果系统 Eight-Chain Causal System 通用
定义：FIS-001核心：产业变化的八环节因果传导链条
消费者→需求→场景→渠道→产品→技术→供应链→产业格局。方向不可逆。正向追溯变化源头，反向推演影响路径。所有分析以八链为底层框架。
五世界（卤味） Five Worlds (Braised Food) 通用
定义：卤味产业内部分为五个竞争逻辑不同的世界
休闲卤味（绝味/周黑鸭等）、佐餐卤味（紫燕等）、地方卤味（煌上煌等区域性品牌）、餐饮卤味（火锅店卤味/盛香亭等）、工业卤味（预制菜/卤味原料）。不同世界竞争逻辑完全不同。
连锁化率 Chain Penetration Rate 通用
定义：衡量品类全国化潜力的核心指标
反映一个品类中连锁品牌门店占比。连锁化率低说明品类分散、品牌化程度低；连锁化率高说明标准化可行、可复制性强。用于FIF-002全国化分析框架。
价格带 Price Band 通用
定义：品类/品牌的价格分布区间与竞争空间
价格带决定品类内竞争格局和利润空间。如早餐价格带锁死商业模式——低价格带限制了成本结构、供应链方式和扩张路径。
品类势能 Category Momentum 通用
定义：品类的结构性增长动力和天花板判断
由需求确定性、供给弹性、场景延展性、可标准化程度等因子综合决定。用于判断品类势能而非证明商业成立。品类的结构性天花板往往比品牌自身天花板更早到来。
多品类验证 Cross-Category Validation 通用
定义：跨品类验证框架的适配性和可靠性
FoodIntelAI的核心方法论原则之一。任何框架在一个品类验证后，迁移至另一品类需重新验证。已验证品类：卤味、炸鸡、早餐、面食。待验证：烘焙、茶饮、火锅。
数据缺口表 Data Gap Table 通用
定义：研究启动时识别和记录数据缺失区域的工具
FIM-001八步研究法的前置工具。在研究前明确哪些数据已获取、哪些需要补充、哪些无法获取。防止研究过程中被数据缺失阻塞，确保研究可推进。
产业推理能力 Industrial Reasoning Capability 通用
定义：FoodIntelAI的核心产品——可复现的产业诊断路径
不是知识库，而是推理能力。知识可以被复制，真正难以复制的是产业推理能力。目标是让每一个判断都有依据，每一个结论都可验证，每一个方案都能复现。
