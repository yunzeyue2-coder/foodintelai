一、这个模型是什么，不是什么

维度是不是
形态经营工具：输入原料价、规格、出成、工艺、人工、包装、渠道与履约参数，输出单位贡献行业研究报告：读完知道很多，但算不出一个数
输出单位贡献 ＋ 结果等级 ＋ 主要限制因素 ＋ 升级路径一个确定的利润数字
证据不足时输出"不可计算"＋缺口清单＋补齐顺序用行业均值把表格填满
竞争判断竞品价格是外部事件，不进入模型；价格战由自己的单位贡献决定竞品跟随器
用途边界决策辅助投资承诺／对外报价承诺

二、模型的三条边界（先知道它不能做什么）

① 不预测价格：所有风险情景只给路径与动作，不给价格预测（缺到岸价、库存与替代弹性）。

② 不替代实测：人工、能耗、渠道扣点、账期等未入库项，缺一项就不产出最终贡献。

③ 不替代人：合规判断、标签审核、宣称文案、承担主体认定一律转人工。

三、核心方法论（三条，全篇冻结）

1｜证据边界：C ≠ 不可计算，未入库 ＝ 不具备计算资格

参数类型能不能算怎么用
C｜情景参数可以计算结果受 Grade Cap 限制，降级使用（仅内部排序）
未入库不具备计算资格结果不产出，给缺口清单与补齐顺序

2｜两条独立轴：证据等级 与 经营结果 互不替代

证据轴：C → A（可信度提高）。经营轴：数值可能同时变差——出成由 100% 实测为 95%，数据更准了，结果却更差。两条轴必须分开表达：不得用"数据更准了"暗示"结果更好了"。

3｜两个闭环必须分开陈述

闭环状态说明
模型逻辑闭环✅采集 → 验证 → 入模 → 计算 → 分级 → 触发 → 重算／拒答 → 执行 → 回流
工程接线闭环✅自建标准件已就绪：DATA 38 字段字典 V1.0 ＋ R1 公式注册表 V1.0 ＋ 接口 Schema

五、一页速查卡

主链

原料规格

▼
工艺转换（参数 → 物性 → 出成）
▼

▼
单位贡献 ＋ 结果等级

三个公式

C(Y) = P ÷ th ÷ tr ÷ Y　　　　　　　　　　原料侧单位成本
A = 实际成交价 − 渠道直接扣除项　　　　渠道净实现收入
B = A − 经营主体承担项　　　　　　　　　经营净实现收入
U = B − C(Y) − 加工成本 − 包装　　　　　单位贡献
结果等级 = min(输入等级)　　　　　　　　　Grade Cap

四态优先级（命中即返回，只有一个状态）

1红线 → 停止计算 ＋ 转人工
2未入库 → 停止计算 ＋ 缺口清单
3结构变化 → 重算（全链）
4等级下降 → 降级（仅内部排序）
5正常 → 正常输出

五档证据

档位含义是否进入计算
A｜事实参数官方统计、法规、可靠实测✅ 可以
B｜行业基准多源交叉、行业公开数据⚠️ 可作基准，禁伪装成实测
C｜情景参数本厂经验、访谈、沙盒假设⚠️ 只能进入情景模型
未入库没有足够证据❌ 不进入计算
M｜模型宪法口径模型人为规定的分母与口径✅ 仅作口径，不作为外部事实

六、十三步完整走查（把模型跑一遍）

01采集：原料采购价 24.0 元/kg（B）；th／tr／Y 暂无实测 → 先用 C 类情景
02入模：C(Y) = 24.0 ÷ 0.93 ÷ 0.98 ÷ 1.00 = 26.33 元/kg
03渠道：实际成交价 70（B）；扣项为情景值 → A 64.50、B 54.40
04加工成本：未入库
05状态判定：命中"未入库" → 停止计算 ＋ 缺口清单
06补情景值：加工 6.00（C）→ U = 20.27 元/kg
07结果等级：C（因 th／tr／Y、扣项、加工均为 C 类）
08用途限定：降级——仅内部排序；对外须标注"待实测校准"
09报价：三档而非单点 → 保守 17.34｜基准 20.27｜进取 22.66
10实测回流：验收单替换 th／tr／Y → 出成实测 95%（证据等级升 A）
11状态复判：th／tr 仍为 C → 结果等级仍为 C（单点升级不改变等级）
12复算触发：原料 ＋5% → C 27.65 → U 18.95 → 触发重新报价
13升级路径：按"消灭最弱输入"补齐 → 等级方可提升

这一遍走查就是本模型的全部用法。八卷正文，只是把这十三步逐一讲透、给出算例与边界。
