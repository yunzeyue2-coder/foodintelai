区域食品生态模型

EVIDENCE-CALIBRATED FOOD ECOSYSTEM INTELLIGENCE MODEL · 证据校准型区域食品生态判断模型
DEFINITION
用于分析区域食品品类从地方生态、产业基础、产品结构，到标准化、商业化、全国化演化过程的产业研究框架。它不是评分模型，而是证据约束型产业判断系统——证据等级决定判断精度，不制造虚假的确定性。
WHY
很多商业报告的问题不是没有观点，而是用低质量数据制造高确定性结论。本模型反向操作：证据不足 → 禁止精确评分 → 只能区间 → 只能判断 → 只能提出待验证命题。证据校准是本模型真正的壁垒，七维只是结构。
SCOPE
适用于地方食品品类、区域传统美食的产业演化分析，以及品类全国化机会判断。它不是：品类选择模型（不回答该不该选）、单店模型（不回答怎么开店）、投资模型（不回答值不值得投）。

〇、核心原则：证据校准评估体系

逻辑链：Evidence → Precision → Model Availability

每个维度固定输出：判断结果（定性）/ 评分精度（区间或暂不量化）/ 证据等级 / 依据（真实来源）/ 验证状态 / 待补数据 / 模型可用状态。

证据等级定义允许的表达精度
A公开数据/可数数据直接支撑（门店数、市场规模等硬数字）可给单一分数，需注明计算依据
B多来源研究交叉验证，但本质是定性归纳只给区间（如 70-85）
C专家判断/研究团队归纳，无法交叉验证只给方向性判断 + 窄区间，标注"研究判断"
D案例推断（从个别案例外推到品类整体）不出分数，只给判断方向，标注"待数据增强"
E假设（尚无证据，仅为待验证命题）不出分数，只列为待验证问题
模型可用状态含义下游调用方式
Ready可进入计算FDE 可直接作为决策变量
Partial辅助判断可参与判断，不单独作为决策依据
Reference仅作为背景只能在解释文本中引用，不进模型
Need Data暂不可调用标记为待补数据项
架构链：FIF-37 → Evidence Calibration → Model Availability → FDE 商业决策引擎 → 行业案例验证

一、七维生态判断框架

维度判断问题关键变量
① 产业基础层
Industrial Base		有没有产业土壤原料产区依赖度 / 供应链成熟度 / 工业化程度
② 地域生态层
Regional Ecology		为什么诞生在这里地理环境 / 农产品基础 / 饮食文化 / 人口迁移
③ 产品形态层
Product Architecture		能不能形成统一认知产品边界清晰度 / 品类命名统一度 / 消费认知成本
④ 技术工艺层
Process Barrier		能不能复制技术依赖 / 师傅依赖 / 设备依赖 / 时间窗口
⑤ 风味资产层
Flavor Asset		味觉能不能跨区域迁移风味识别度 / 文化绑定度 / 外地接受成本 / 替代可能性（对应味觉半径四变量）
⑥ 交付系统层
Delivery System		能不能适应现代消费最佳赏味时间 / 堂食依赖 / 外卖适配 / 标准化损耗
⑦ 全国化层
Scaling Potential		能不能规模复制供应链迁移 / 品牌表达 / 门店复制 / 价格带空间（对应全国化三重约束模型）

二、三个分析模块（Analysis Modules）

模块一 · 区域食品生态分析模块
输入：任意地方品类（如"河南烩面"）
输出：产业优势 / 最大限制 / 迁移风险，均按证据等级标注，不强行给综合分
依赖：产业基础层 + 地域生态层
模块二 · 风味迁移风险模块
输入：品类的风味结构描述
输出：Flavor Transfer Index（方向性风险判断，不是精确指数值），由地方依赖度 / 味觉冲击强度 / 文化理解成本 / 替代难度四子变量构成
约束：四子变量目前普遍只能到证据等级 C；在跨区域消费数据（外地门店复购率、退货/差评关键词）到位前，不允许升级为 Ready 状态的精确数字
模块三 · 全国化路径判断模块
输入：品类的供应链/品牌/消费认知现状
输出：该品类应走哪类路径——供应链型 / 品牌型 / 加盟型 / 工业化型（定性判断，附带每条路径成立的前提条件），不输出"综合评分"

三、行业验证案例：中国米线产业生态验证

FIF-37 首个行业验证案例——以下不是"米线的标准答案"，是框架用米线六天研究数据做的第一次验证记录，用于检验框架本身是否可用。

维度判断证据依据模型可用
产业基础层强B全国米粉门店34万家，市场规模775亿元、同比+8.4%（红餐大数据，2025.3/2024）Partial
地域生态层强B七大区域体系 Day1-5 完成对比，区域分化明显Partial
产品形态层中等偏弱C米线/米粉/卷粉/河粉命名边界模糊（蒙自源1700家/1474家口径冲突即反映统计与命名不统一）Reference
技术工艺层存在挑战D重汤重鲜慢消费工艺与工业化复制存在张力，缺损耗率/设备标准化率硬数据Need Data
风味资产层中等偏弱C云南早餐/重汤/慢消费场景与全国午餐/快节奏场景存在系统性差异Reference
交付系统层堂食依赖高C云南米线强调现煮热汤，外卖适配有限Reference
全国化层中等B四种迁移机制均已尝试但未跑通全流程；头部品牌停在千店级（蒙自源超1700家、阿香670家）Partial
综合判断（不出综合分）：区域资产强，产业基础较强，全国化能力中等。最大限制：产品形态分裂（C级）× 风味迁移成本（C级）。主要机会：供应链标准化 + 产品命名/认知统一。

后续案例积累方向：麻辣烫 / 牛肉面 / 烧烤 / 饺子 等品类逐个挂接本框架验证。

四、下一步升级路径

证据等级不是固定的，接入数据源后可逐级收紧：

  • 美团/窄门餐眼门店数据 → 产品形态层、交付系统层 可能从 C 升到 B
  • 高德 POI 数据 → 地域生态层 可能从 B 升到 A
  • 企业/供应链数据 → 技术工艺层 可能从 D 升到 C
  • 跨区域消费者调研 → 风味资产层 可能从 C 升到 B
升级规则：任何等级跃迁，必须附带新增数据来源说明，不能凭"感觉更有把握了"直接调高等级。
